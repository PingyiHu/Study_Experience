# 流程

DeepSeek-R1 使用了冷启动 + 多阶段训练的方式：

- 阶段1：使用少量高质量的 CoT 数据进行冷启动，预热模型。
- 阶段2：进行面向推理的强化学习，提升模型在推理任务上的性能。
- 阶段3：使用拒绝采样和监督微调，进一步提升模型的综合能力。
- 阶段4：再次进行强化学习，使模型在所有场景下都表现良好。

# 阶段1 冷启动

- 收集ZERO生成的优秀CoT链
- few shot ICL生成的一些优秀的长CoT

# 阶段2 进行RL

- 针对特定推理任务GRPO
- 引入语言一致性奖励

# 阶段3 拒绝采样

对当前RL的模型拒绝采样，获取高质量的SFT数据：

- 推理数据拒绝采样
- 非推理任务也有一部分数据

# 阶段4 继续RL

对推理任务和非推理任务都进行训练：

- 推理任务可以用reward model，或是rule base的方式训练
- 非推理任务直接用已经训好的reward model
