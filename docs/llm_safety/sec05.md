# 5. 综合学习路线图

> Comprehensive Learning Roadmap

经过前四章对越狱攻击、后门攻击、提示注入攻击和Agent安全四个方向的系统梳理，本章提供一个从基础到前沿的三阶段学习路径、一张跨方向的关键Benchmarks汇总表，以及按优先级排序的阅读推荐，帮助研究者在有限时间内构建最扎实的知识体系。

---

## 5.1 整体学习路径规划

### 5.1.1 第一阶段（基础）：越狱攻击与安全对齐原理

LLM安全研究的逻辑起点是理解**安全对齐**（Safety Alignment）的基本原理及其脆弱性。学习者应首先精读Wei等人提出的竞争目标与泛化错配理论[^1^]，这两个框架是整个领域的标准分析透镜——竞争目标揭示了有用性与安全性之间的优先级冲突，泛化错配则解释了OOD输入为何能绕过安全训练。在此基础上，通过GCG[^2^]和AutoDAN[^3^]掌握白盒攻击的梯度优化与遗传算法两条技术路线，通过PAIR[^4^]和TAP[^5^]理解黑盒攻击中LLM自我迭代的核心思想。此阶段的完成标志是能够独立解释任意越狱攻击的成功机理，并判断其属于哪种攻击类型。

### 5.1.2 第二阶段（深入）：训练时攻击与推理时攻击的联动理解

第二阶段将视野扩展到训练时与推理时攻击的完整谱系。**后门攻击**方向从Sleeper Agents[^8^]入手，理解后门持久性原理——为何标准安全训练无法消除已植入的后门；通过BadChain[^9^]掌握CoT推理劫持，通过BadStyle理解触发器从字符级到风格级的演进。**提示注入攻击**方向以Perez与Ribeiro的开山之作[^6^]和Greshake等人的间接注入研究[^7^]建立威胁模型认知，再通过Instruction Hierarchy[^12^]和Rennervate理解防御分野——前者让模型内建指令优先级，后者利用注意力特征实现token级精确检测。此阶段的关键认知突破在于意识到后门与提示注入并非孤立现象：二者结合形成的"后门+注入"复合攻击是Agent场景中最危险的威胁向量。

### 5.1.3 第三阶段（前沿）：Agent安全与系统级威胁模型

第三阶段聚焦于Agent安全这一最具实践紧迫性的前沿方向。以ReAct架构[^15^]为分析框架，系统审视Thought-Action-Observation循环中每个环节的安全弱点：间接提示注入攻击Observation环节[^7^]，工具选择劫持攻击Action环节，CoT暴露攻击Thought环节。在此基础上，ClawWorm展示了Agent生态中级联崩溃的可能性，ToolSafe的步骤级护栏代表了主动防御的范式转变[^19^]，MCPSecBench将安全研究推向了协议层[^20^]。完成此阶段应具备设计系统级安全架构的能力，能够在具体场景中权衡能力开放度与风险控制度。

## 5.2 关键资源汇总

### 5.2.1 顶级会议跟踪列表

LLM安全研究成果主要发表在三个领域的顶级会议。机器学习方向的**NeurIPS、ICML、ICLR**是越狱攻击、后门攻击和对抗训练类论文的核心平台，Wei等人[^1^]的越狱理论、Hubinger等人[^8^]的Sleeper Agents、Ruan等人[^14^]的ToolEmu均发表于此。自然语言处理方向的**ACL、EMNLP**更关注提示注入与安全对齐的交叉议题，ProAttack[^10^]、ONION[^11^]、Instruction Hierarchy[^12^]属于此类。系统安全方向的**IEEE S&P、NDSS、USENIX Security**是Agent安全和系统级防御的主要阵地，Rennervate和ToolHijacker发表于NDSS。建议根据研究方向选择2-3个会议持续跟踪，同时关注arXiv预印本获取最新动态。

### 5.2.2 关键Benchmarks汇总表

四个方向各自拥有标准评测工具，下表系统汇总13个关键Benchmarks。

| 研究方向 | Benchmark | 核心评测目标 | 规模与覆盖 | 推荐使用者 |
|:---|:---|:---|:---|:---|
| **越狱攻击** | JailbreakBench | 越狱攻击标准化评测 | 多种攻击方法×多种目标模型 | 越狱攻防方法研究者 |
| | AdvBench | 有害行为请求数据集 | 520个有害行为请求 | 攻击方法快速验证 |
| | HarmBench | 攻击与防御综合评估 | 集成标准分类器和评估协议 | 系统性攻防评估 |
| **后门攻击** | BackdoorLLM | 后门攻击综合基准 | 8种攻击策略，多种评估指标 | 后门攻防深度研究 |
| | AgentPoison | 自动化后门评估框架 | 支持ReAct/AutoGen架构 | 自动化后门攻击复现 |
| **提示注入** | AgentDojo | 动态智能体安全评测 | 97个任务，629个安全测试用例 | 提示注入与Agent安全研究 |
| | HackAPrompt | 直接注入大规模数据集 | 600,000+对抗性提示 | 注入检测分类器训练 |
| | BIPIA | 间接注入专用基准 | 250个攻击目标，5个应用场景 | 间接注入与RAG安全研究 |
| **Agent安全** | ToolEmu | 沙箱仿真评测 | 36个工具包，144个高风险任务 | Agent风险识别与原型验证 |
| | ASB | 综合安全能力评估 | 10个场景，10类Agent，400+工具 | 系统性Agent安全能力评估 |
| | MCPSecBench | MCP协议安全评测 | 17种攻击类型，4个攻击面 | 协议层安全研究 |
| | TS-Bench | 步骤级工具调用安全 | 细粒度步骤级检测数据 | 主动防御与护栏研究 |
| | AgentHarm | 有害行为合规评测 | 110个恶意任务，11个危害类别 | Agent安全对齐能力评测 |

上表呈现的Benchmarks覆盖了从单模型越狱到多Agent系统安全的完整评测需求，实际选择需考虑三个维度的权衡。其一，**评测粒度**：JailbreakBench关注单次输入-输出层面的攻击成功与否，AgentDojo评估多轮交互中的复合指标，TS-Bench将粒度细化到推理步骤级别[^19^]。其二，**评测环境**：ToolEmu采用模拟沙箱设计，适合早期原型验证；AgentDojo在真实API调用环境中评估，更接近实际部署[^13^]。其三，**领域覆盖**：MCPSecBench[^20^]是当前唯一覆盖MCP协议四方模型（Host/Client/Server/Protocol）的评测工具，对于研究Agent生态互联安全具有不可替代性。建议根据研究阶段选择主评测平台，并辅以其他Benchmark进行交叉验证。

### 5.2.3 推荐阅读优先级排序

在前四章40篇论文的基础上，以下按"必读—重要—进阶"三级给出阅读优先级建议。

**必读论文（★★★★★）—— 5篇建立认知骨架的核心工作**。Wei等人（NeurIPS 2023）的竞争目标与泛化错配理论[^1^]是理解所有越狱攻击的根本出发点，难度入门但思想深邃。Zou等人（2023）的GCG[^2^]开创了对抗性后缀优化方向，是白盒攻击的技术基石，建议结合开源代码理解梯度优化在离散token空间中的实现。Greshake等人（AISec 2023）的间接注入研究[^7^]将威胁模型从用户输入扩展到整个数据供应链，对Agent安全具有奠基意义。Hubinger等人（2024）的Sleeper Agents[^8^]以大规模实验证明了安全训练无法消除后门，是后门持久性研究的标杆。Wallace等人（2024）的Instruction Hierarchy[^12^]代表了从模型训练层面解决提示注入问题的重要尝试。

**重要论文（★★★★☆）—— 10篇深化方向理解的关键工作**。越狱方向推荐AutoDAN[^3^]、PAIR[^4^]和TAP[^5^]，分别代表遗传算法、LLM迭代和树状搜索三条自动化攻击路线。后门方向推荐BadChain[^9^]和ONION[^11^]，前者开创CoT推理劫持范式，后者是防御基线的标准参照。提示注入方向推荐Perez与Ribeiro的开山之作[^6^]、AgentDojo[^13^]和Rennervate，覆盖从攻击定义到动态评测再到token级防御的完整研究链。Agent方向推荐ReAct[^15^]、ToolEmu[^14^]和Yu等人（KDD 2025）的综述[^18^]，分别提供架构理解、评测方法论和全景式威胁地图。

**进阶论文（★★★☆☆）—— 5篇追踪前沿的最新工作**。LatentBreak将攻击从token层面推进到表示空间；AgentPoison[^17^]揭示记忆层攻击这一此前被忽视的攻击面；ToolHijacker将注入攻击面从工具调用前移至工具选择阶段；ToolSafe[^19^]代表从"检测-响应"到"预测-预防"的防御范式转变；MCPSecBench[^20^]将Agent安全研究从模型层推向协议层。这5篇论文各自代表其方向的最前沿进展，建议在完成必读和重要论文后再深入研读。
