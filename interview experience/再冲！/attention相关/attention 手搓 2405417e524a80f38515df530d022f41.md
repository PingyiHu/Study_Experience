# attention有什么用？

- **计算关联权重（Attention Scores）**
    
    对于当前 token（Query），模型会计算它与所有其他 token（Keys）之间的相似度（通常是点积）。
    
- **加权信息整合（Weighted Sum）**
    
    根据这些权重，从所有 token 的表示（Values）中加权汇总出上下文向量。
    
- **结果：具备全局依赖建模能力**
    
    这样，模型在理解或生成每个词时，都能“看到”整个句子甚至整个文档，从而捕获长距离依赖。
    

# self attention

```python
import torch
import torch.nn as nn
from math import sqrt

class SelfAttention(nn.Module):
    def __init__(self, input_dim, dim_q_k, dim_v):
        self.q = nn.Linear(input_dim, dim_q_k)
        self.k = nn.Linear(input_dim, dim_q_k)
        self.v = nn.Linear(input_dim, dim_v)

        self.norm = sqrt(dim_q_k)
    
    def forward(self, x):
        # (b, s, input_dim) -> (b, s, dim_q_k)
        q = self.q(x)
        k = self.k(x)
        # (b, s, input_dim) -> (b, s, dim_v)
        v = self.v(x)

        # (b, s, s)
        d = torch.bmm(q, k.transpose(1, 2))/self.norm
        softmax_out = torch.softmax(d, dim=-1)

        # (b, s, dim_v)
        attn_out = torch.bmm(softmax_out, v)
        return attn_out
```

- `torch.bmm` 是对一批二维矩阵做矩阵乘法的函数，适用于批处理场景，要求输入张量的 batch 维度一致。（对后面两个维度进行矩阵乘法）

# Cross attention

- 跨序列进行attention计算，多用于encoder和decoder之间
- q来自于解码器的输入，kv来自于编码器的输出
    - q是关键词，是当前decoder已知信息
    - k是标签，v是值，是当前encoder的已知信息
    - 以翻译任务为例：
        - 一开始decoder只有一个已知信息<bos>
        - 我们可以从encoder方面得到的信息推断当前<bos>的hidden states，从而得到下一个token
        - 翻译任务中在cross attention部分的encoder的hidden states和decoder的hidden states在经过attention矩阵QKV之后，是对齐的
        - 同理，cross attention也可以用在多模态的任务中，进行文本和图像的对齐

![image.png](attention%20%E6%89%8B%E6%90%93/image%205.png)

![image.png](attention%20%E6%89%8B%E6%90%93/image%206.png)

```python
import torch
import torch.nn as nn
from math import sqrt

class CrossAttention(nn.Module):
    def __init__(self, input_dim, dim_q_k, dim_v):
        self.q = nn.Linear(input_dim, dim_q_k)
        self.k = nn.Linear(input_dim, dim_q_k)
        self.v = nn.Linear(input_dim, dim_v)

        self.norm = sqrt(dim_q_k)
        
    def forward(self, encoder_input, decoder_input):
        # (b, s1, input_dim) -> (b, s1, dim_q_k)
        q = self.q(decoder_input) 
        # (b, s2, input_dim) -> (b, s2, dim_q_k)
        k = self.k(encoder_input)
        # (b, s2, input_dim) -> (b, s2, dim_v)
        v = self.v(encoder_input)

        # (b, s1, s2)
        a = torch.bmm(q, k.transpose(1, 2))/self.norm
        softmax_out = torch.softmax(a, dim=-1)

        # (b, s1, dim_v)
        cross_attn_out = torch.bmm(softmax_out, v)
        return cross_attn_out
```

# Multi-head attention

- 将原来的一整个QKV矩阵分为很多组小的QKV矩阵，每个矩阵捕捉不同的信息
- 先分割，最后再拼接

![image.png](attention%20%E6%89%8B%E6%90%93/image%207.png)

```python
class MultiHeadSelfAttention(nn.Module):
    def __init__(self, input_dim, head, dim_q_k, dim_v):
        self.head = head
        self.dim_per_head_q_k = dim_q_k // head
        self.dim_per_head_v = dim_v // head

        self.q = nn.Linear(input_dim, self.dim_per_head_q_k)
        self.k = nn.Linear(input_dim, self.dim_per_head_q_k)
        self.v = nn.Linear(input_dim, self.dim_per_head_v)
        
        self.norm = sqrt(self.dim_per_head_q_k)
				
				# 如果是transformer block的话，需要将输出维度重新对齐到输入的维度
        self.out = nn.Linear(dim_v, input_dim)
    
    def forward(self, x):
        # (b, s, word_dim)
        b = x.size(0)
        s = x.size(1)
				
				# 多头的意思不是初始化多个线性层，而是将原来的线性层拆分为多个线性层
        # (b, s, word_dim) -> (b, head, s, dim_per_head_q_k)
        q = self.q(x).view(b, -1, self.head, self.dim_per_head_q_k).transpose(1, 2)
        k = self.k(x).view(b, -1, self.head, self.dim_per_head_q_k).transpose(1, 2)
        # (b, s, word_dim) -> (b, head, s, dim_per_head_v)
        v = self.v(x).view(b, -1, self.head, self.dim_per_head_v).transpose(1, 2)
        
        # (b, head, s, s)
        d = torch.matmul(q, k.transpose(2, 3)) // self.norm
        softmax_out = torch.softmax(d, dim=-1)

        # (b, head, s, dim_per_head_v)
        attn_out = torch.matmul(softmax_out, v)
        
        # 相当于把同一sequence的所有head都并排放在一起
        # (b, head, s, dim_per_head_v) -> (b, s, dim_v) 
        attn_out = attn_out.transpose(1, 2).contiguous().view(b, s, -1)
        
        # (b, s, dim_v) -> # (b, s, input_dim)
        out = self.out(attn_out) 
        return out
```

- matmul可以处理更广泛的矩阵乘法；bmm只处理3维的，并且第一维为batchsize
- **contiguous() 的作用是确保张量在内存中连续存储**：类似 transpose()、permute() 等一些操作，会使张量的存储顺序发生变化，导致张量在内存中不再是连续存储的。这种情况下，如果你直接对张量进行 view() 操作，可能会引发错误。

# Multi-head cross attention

```python
class MultiHeadCrossAttention(nn.Module):
    def __init__(self, head, input_dim, dim_q_k, dim_v):
        self.head = head
        self.dim_q_k_per_head = dim_q_k // head
        self.dim_v_per_head = dim_v // head
        
        self.q = nn.Linear(input_dim, dim_q_k)
        self.k = nn.Linear(input_dim, dim_q_k)
        self.v = nn.Linear(input_dim, dim_v)
        
        self.norm = sqrt(self.dim_q_k_per_head)
        
        # 如果是transformer block的话，需要将输出维度重新对齐到输入的维度
        self.out = nn.Linear(dim_v, input_dim)

    def forward(self, encoder_input, decoder_input):
        b = encoder_input.size(0)
        s_e = encoder_input.size(1)  # encoder sequence length
        s_d = decoder_input.size(1)  # decoder sequence length

        # (b, head, s_d, dim_q_k_per_head)
        q = (
            self.q(decoder_input)
            .view(b, -1, self.head, self.dim_q_k_per_head)
            .transpose(1, 2)
        )
        # (b, head, s_e, dim_q_k_per_head)
        k = (
            self.k(encoder_input)
            .view(b, -1, self.head, self.dim_q_k_per_head)
            .transpose(1, 2)
        )
        # (b, head, s_e, dim_v_per_head)
        v = (
            self.v(encoder_input)
            .view(b, -1, self.head, self.dim_v_per_head)
            .transpose(1, 2)
        )

        # (b, head, s_d, s_e)
        qk = torch.matmul(q, k.transpose(2, 3)) / self.norm
        softmax_out = torch.softmax(qk, dim=-1)

        # (b, head, s_d, v)
        attn_out = torch.matmul(softmax_out, v)

        # (b, s_d, head, v)
        attn_out = attn_out.transpose(1, 2).contiguous().view(b, s_d, -1)

        return self.out(attn_out)
```

# Masked self attention

transformer block的第一个attention层就是masked self-attention，其实就是将该token之后的所有的token的注意力分数置为0，只保留当前token及其之前的注意力分数

为什么需要这样的attention：

- 因为decoder是自回归进行生成，每一个当前生成的token依赖于之前的token，而不依赖于之后生成的token
- 在训练的时候我们是去模拟这个自回归的过程的，虽然是一口气将所有的输入放入进行计算（teacher forcing）
- 在训练的时候，肯定会引入padding，这样的padding也需要被掩盖

- eos推出pad，好像也无所谓
- pad token通常还是eos

## 掩码生成代码

- 通常在进行分batch的时候，掩码就会提前生成好
- 掩码的形状是(batchsize, 1, seqlen, seqlen)，为了之后多头注意力机制的qk（注意力分数）和v的乘积那一步做准备，第1维的这个1会直接广播成head的个数。

```python
def build_mask(seq, pad_id):
    """
    seq: (B, T)  右 padding，B是batchsize，T是seqlen
    return: (B, 1, T, T)  已合并 causal + padding 的掩码
    """
    B, T = seq.shape
    device = seq.device

    # 1) causal mask  (下三角 1)
    causal_mask = torch.tril(torch.ones(T, T, device=device)).bool()   # (T, T)

    # 2) padding mask (有效 token=1, pad=0)
    padding_mask = (seq != pad_id).unsqueeze(-2)                      # (B, 1, T)

    # 3) 合并：逐位与并扩展维度
    mask = causal_mask & padding_mask                                  # (B, T, T)
    mask = mask.unsqueeze(1)                                          # (B, 1, T, T)

    # 4) 转成 -inf
    return mask.float().masked_fill(~mask, float('-inf'))             # (B, 1, T, T)
```

# 为什么模型输入有上限

从encoder的构造来看，他是只关心输入的维度的，也就是多长的序列好像都能进行运算。

有上限的原因：

- 位置编码的长度有上限，需要考虑外推和内插
- 显存大小和算力制约
- **训练分布的语义漂移：**语言模型在训练时只见过**固定长度窗口内的依赖**。超长上下文里，远距离共现 patterns 几乎没出现过，模型即便算得动，**语义建模也会迅速退化**（重复、跑题、胡说）。
