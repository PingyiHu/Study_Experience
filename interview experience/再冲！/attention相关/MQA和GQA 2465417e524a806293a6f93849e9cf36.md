# 多查询注意力机制MQA

是多头注意力机制的一个变种，在这个情况下所有的头的kv参数矩阵只保留一份，但是q参数矩阵还是原来的个数。

# 分组查询注意力机制GQA

虽然MQA方式大幅减小了参数数量，但是，带来推理加速的同时会造成模型性能损失，且在训练过程使得模型变得不稳定（**复杂度的降低可能会导致质量下降和训练不稳定**），因此在此基础上提出了GQA，它将Query进行分组，每个组内共享一组Key、Value。

分为g个group，nh为head个数，每nh//g个head共享一个kv。

![image.png](MQA%E5%92%8CGQA/image%202.png)

下面是代码，expand扩展，shape中为1的维度

```python
from torch import nn
import torch
import math

class MultiheadAttn(nn.Module):
    def __init__(self, embed_dim, head_dim, head_num, Group):
        super().__init__()
        self.embed_dim = embed_dim
        self.head_dim = head_dim
        self.head_num = head_num
        self.Group = Group

        **self.k_linear = nn.Linear(embed_dim, Group * head_dim)
        self.v_linear = nn.Linear(embed_dim, Group * head_dim)**
        self.q_linear = nn.Linear(embed_dim, embed_dim)

        self.out_linear = nn.Linear(embed_dim, embed_dim)

        self.norm = math.sqrt(head_dim)

    def forward(self, key, query, value, mask):
        bz = key.shape[0]
        seq_len = key.shape[1]

        k = self.k_linear(key)
        q = self.q_linear(query)
        v = self.v_linear(value)

        q = q.view(bz, seq_len, self.head_num, self.head_dim).transpose(1, 2)

        k = k.view(bz, seq_len, self.Group, self.head_dim).transpose(1, 2)
        v = v.view(bz, seq_len, self.Group, self.head_dim).transpose(1, 2)

        k = (
            k.unsqueeze(2)
            .expand(bz, self.Group, self.head_num // self.Group, seq_len, self.head_dim)
            .reshape(bz, self.head_num, seq_len, self.head_dim)
        )
        v = (
            v.unsqueeze(2)
            .expand(bz, self.Group, self.head_num // self.Group, seq_len, self.head_dim)
            .reshape(bz, self.head_num, seq_len, self.head_dim)
        )

        attn_logits = torch.matmul(q, k.transpose(-2, -1)) / self.norm
        if mask:
            attn_logits = attn_logits + mask
        attn_score = nn.functional.softmax(attn_logits, dim=-1)

        attn_out = attn_score @ v
        attn_out = (
            attn_out.transpose(1, 2).contiguous().view(bz, seq_len, self.embed_dim)
        )

        return self.out_linear(attn_out)
```
