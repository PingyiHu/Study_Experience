# 爬楼梯

Tags: 动态规划
URL: https://leetcode.cn/problems/climbing-stairs/description/

# 我的方法

这个其实就是斐波那契数列。

```cpp
class Solution
{
public:
    int climbStairs(int n)
    {
        if (n <= 3)
            return n;
        vector<int> v(n + 1, 0);
        v[1] = 1;
        v[2] = 2;
        for (int i = 3; i <= n; i++)
        {
            v[i] = v[i - 1] + v[i - 2];
        }
        return v[n];
    }
};
```
