# 96.不同的二叉搜索树

Tags: 动态规划
URL: https://leetcode.cn/problems/unique-binary-search-trees/description/

# 随想录方法

dp[i]就是节点个数为i的二叉搜索树的个数

空树也是二叉搜索树，因此dp[0]为1

```cpp
class Solution
{
public:
    int numTrees(int n)
    {
        vector<int> dp(n + 1, 0);
        dp[0] = 1;
        dp[1] = 1;
        dp[2] = 2;
        for (int i = 3; i <= n; i++)
        {
            for (int j = 1; j <= i; j++)
            {
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }
        return dp[n];
    }
};
```
