# 输入输出

Tags: python基础

## 1. 基本输入

### 1.1 单行输入

```python
x = input()  # 读入一整行，返回 str

```

C++ 对应：

```cpp
string x;
cin >> x;

```

---

### 1.2 转换为数字

```python
n = int(input())        # 单个整数
x = float(input())      # 浮点数

```

---

### 1.3 读入多个数

```python
a, b = map(int, input().split())

```

C++ 对应：

```cpp
int a, b;
cin >> a >> b;

```

---

### 1.4 读入列表

```python
nums = list(map(int, input().split()))

```

C++ 对应：

```cpp
vector<int> nums(n);
for (int i=0; i<n; i++) cin >> nums[i];

```

---

### 1.5 多行输入

```python
n = int(input())
arr = [list(map(int, input().split())) for _ in range(n)]

```

C++ 对应：

```cpp
int n;
cin >> n;
vector<vector<int>> arr(n, vector<int>(m));
for (...) ...

```

---

## 2. 文件输入

```python
with open("input.txt", "r") as f:
    data = f.read()        # 读整个文件
    lines = f.readlines()  # 读成列表（按行）

```

C++ 对应：

```cpp
ifstream f("input.txt");
string line;
getline(f, line);

```

---

## 3. 基本输出

### 3.1 打印变量

```python
print("Hello")
print(a, b)        # 自动空格分隔
print(a, b, sep=", ")  # 自定义分隔符

```

C++ 对应：

```cpp
cout << "Hello\n";
cout << a << " " << b;

```

---

### 3.2 不换行输出

```python
print(a, end="")      # 默认 end="\n"

```

C++ 对应：

```cpp
cout << a;

```

---

### 3.3 格式化输出

```python
name = "Tom"
age = 20
print(f"My name is {name}, age {age}")
print("{:.2f}".format(3.14159))  # 保留两位小数

```

C++ 对应：

```cpp
cout << "My name is " << name << ", age " << age;
printf("%.2f", 3.14159);

```

---

## 4. 快速 I/O（大数据量时）

Python 默认 `input()` 比较慢，可以用：

```python
import sys

data = sys.stdin.read().split()   # 一次性读完
n = int(data[0])
arr = list(map(int, data[1:]))

```

输出：

```python
sys.stdout.write("Hello\n")

```

C++ 对应：

```cpp
ios::sync_with_stdio(false);
cin.tie(nullptr);

```

---

## 5. 小结

| 场景 | Python | C++ |
| --- | --- | --- |
| 单个值输入 | `x = input()` / `int(input())` | `cin >> x` |
| 多值输入 | `a, b = map(int, input().split())` | `cin >> a >> b` |
| 列表输入 | `list(map(int, input().split()))` | 循环 `cin` |
| 文件 I/O | `open()` | `ifstream` / `ofstream` |
| 快速 I/O | `sys.stdin.read()` | `ios::sync_with_stdio(false)` |
