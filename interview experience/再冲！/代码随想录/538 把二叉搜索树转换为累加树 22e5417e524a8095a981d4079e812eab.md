# 538. 把二叉搜索树转换为累加树

Tags: 二叉树
URL: https://leetcode.cn/problems/convert-bst-to-greater-tree/description/

# 我的方法

使用右中左的方式进行遍历。

```cpp
class Solution {
public:
    int traverse(TreeNode* root, int& sum) {
        if (!root)
            return 0;
        traverse(root->right, sum);

        sum += root->val;
        root->val = sum;

        traverse(root->left, sum);

        return sum;
    }

    TreeNode* convertBST(TreeNode* root) {
        int sum = 0;
        traverse(root, sum);
        return root;
    }
};
```
