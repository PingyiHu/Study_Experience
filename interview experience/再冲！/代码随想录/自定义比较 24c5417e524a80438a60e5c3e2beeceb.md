# 自定义比较

Tags: python基础

## **方法 1：`key` + 元组（推荐）**

Python 排序和比较元组时，会**先比较第一个元素**，如果相等再比较第二个，以此类推。

所以只要把两个优先级组合成元组，就能实现多条件比较。

```python
import heapq

class Task:
    def __init__(self, priority1, priority2, name):
        self.priority1 = priority1
        self.priority2 = priority2
        self.name = name

tasks = [
    Task(1, 2, "A"),
    Task(1, 1, "B"),
    Task(0, 3, "C")
]

# sorted 示例（按 priority1 升序，priority2 升序）
tasks_sorted = sorted(tasks, key=lambda t: (t.priority1, t.priority2))
for t in tasks_sorted:
    print(t.priority1, t.priority2, t.name)

# heapq 示例
heap = []
for t in tasks:
    heapq.heappush(heap, ((t.priority1, t.priority2), t))
while heap:
    (p1, p2), t = heapq.heappop(heap)
    print(p1, p2, t.name)

```

输出：

```
0 3 C
1 1 B
1 2 A

```

> 元组比较顺序固定：从左到右逐个比较，第一个不相等就决定结果。
> 
> 
> 这种方法非常像 **C++ `std::pair` 的比较规则**。
>

## **方法 2：类中定义 `__lt__` 多字段比较**

如果比较逻辑固定，可以直接在类里写：

```python
class Task:
    def __init__(self, priority1, priority2, name):
        self.priority1 = priority1
        self.priority2 = priority2
        self.name = name

    def __lt__(self, other):
        if self.priority1 != other.priority1:
            return self.priority1 < other.priority1
        return self.priority2 < other.priority2

tasks = [
    Task(1, 2, "A"),
    Task(1, 1, "B"),
    Task(0, 3, "C")
]

import heapq
heapq.heapify(tasks)  # 直接用对象构建堆
while tasks:
    t = heapq.heappop(tasks)
    print(t.priority1, t.priority2, t.name)

```

## **方法 3：`dataclasses.dataclass(order=True)`**

`dataclass` 带 `order=True` 会自动按字段顺序生成比较方法，非常适合多优先级：

```python
from dataclasses import dataclass

@dataclass(order=True)
class Task:
    priority1: int
    priority2: int
    name: str  # 不参与比较，排在最后不加字段顺序影响

tasks = [
    Task(1, 2, "A"),
    Task(1, 1, "B"),
    Task(0, 3, "C")
]

import heapq
heapq.heapify(tasks)
while tasks:
    t = heapq.heappop(tasks)
    print(t.priority1, t.priority2, t.name)

```

## 方法4：使用元组

```python
heap = [(-s.score, s.age, s) for s in students]
heapq.heapify(heap)

while heap:
    _, _, stu = heapq.heappop(heap)
    print(stu)

```

## **升序 / 降序混合**

如果某个字段要降序，可以取相反数：

```python
key=lambda t: (t.priority1, -t.priority2)

```

这样 priority1 升序，priority2 降序。
