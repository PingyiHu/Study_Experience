# 674. 最长连续递增序列

Tags: 动态规划
URL: https://leetcode.cn/problems/longest-continuous-increasing-subsequence/description/

# 我的方法

dp表示，以i结尾的最长递增序列长度

```python
class Solution(object):
    def findLengthOfLCIS(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        dp = [1] * len(nums)
        max_len = 1
        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                dp[i] = dp[i - 1] + 1
                if dp[i]>max_len:
                    max_len=dp[i]
        
        return max_len
```
