# 19. 删除链表的倒数第 N 个结点

Tags: 链表
URL: https://leetcode.cn/problems/remove-nth-node-from-end-of-list/description/

我的方法：双指针，两个指针间距离固定为n

```cpp
class Solution
{
public:
    ListNode *removeNthFromEnd(ListNode *head, int n)
    {
        ListNode *dummy = new ListNode;
        dummy->next = head;
        ListNode *cur = dummy;
        ListNode *back = cur;
        while (n--)
        {
            back = back->next;
        }
        while (back->next)
        {
            back = back->next;
            cur = cur->next;
        }
        ListNode *tmp = cur->next;
        cur->next = cur->next->next;
        delete tmp;
        return dummy->next;
    }
};
```
