# 344. 反转字符串

Tags: 字符串
URL: https://leetcode.cn/problems/reverse-string/description/

# 我的方法：双指针

```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {
        int i=0;
        int j=s.size()-1;
        while(i<j){
            char temp=s[i];
            s[i]=s[j];
            s[j]=temp;
            i++;
            j--;
        }
    }
};
```
