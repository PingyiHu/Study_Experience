# 公共前缀后缀的定义：已经遍历过的信息记录在前缀表（或者是next数组）之中

所谓的公共前缀后缀，指的是匹配失败位置之前的字符串的前缀和后缀相同的部分，后缀部分如果和前缀有相同的地方，从前缀相同部分的后一个字符开始匹配。

# 如何计算前缀表

下图是不需要减一的前缀表，当匹配不成功时，假设模式串中指针指向的是j，那么继续进行匹配时，需要找到前缀表中j-1的值，因为其中记录的是**下标j-1之前（包括j-1）的字符串中，有多大长度的相同前缀后缀。**

![image.png](28%20%E5%AE%9E%E7%8E%B0%20strStr()/image%201.png)

![image.png](28%20%E5%AE%9E%E7%8E%B0%20strStr()/image%202.png)

下面的代码是使用next数组，也就是正常前缀表每个元素减1得到的。

为什么要减一呢，减一会使得在匹配不成功时可以使用j=next[j]，方便进行回溯，比较的时候会重新变成比较next[i]与next[j+1]，其实和原始的比较前缀表是等价的**。**

![image.png](28%20%E5%AE%9E%E7%8E%B0%20strStr()/image%203.png)

```cpp
void getNext(int* next, const string& s){
    int j = -1; //j指向前缀末尾的位置，i指向后缀末尾的位置
    next[0] = j;
    for(int i = 1; i < s.size(); i++) { // 注意i从1开始
// 前后缀不相同了，相当于将i作为文本串的指针，将j作为模式串的指针，当j+1处匹配失败时，说明之前的j个字符都匹配成功，因此下一次需要比对的位置是next[j]
        while (j >= 0 && s[i] != s[j + 1]) { 
            j = next[j]; // 向前回退，先比对当前
        }
        if (s[i] == s[j + 1]) { // 找到相同的前后缀
            j++;
        }
        next[i] = j; // 将j（前缀的长度）赋给next[i]
    }
}
```

# strstr

## 直接使用前缀数组

next数组保存的是当前这个j之前（包括j）的字符串的最长公共前缀和后缀的长度，**所以next[i]是公共前后缀的后一个字符，需要被拿来比较**。

求next数组的时候是模式串自己和自己进行比较，i不断往后进行遍历，i代表的是后缀；j代表的是前缀，当needle[i]和needle[j]不相等的时候，j回溯。

```cpp
class Solution
{
public:
    vector<int> getNext(string needle)
    {
        vector<int> next(needle.length());
        next[0] = 0;
        int j = 0;
        for (int i = 1; i < needle.length(); i++)
        {
            while (j > 0 && needle[j] != needle[i])
                j = next[j - 1];
            if (needle[j] == needle[i])
                j++;
            next[i] = j;
        }
        return next;
    }

    int strStr(string haystack, string needle)
    {
        vector<int> next = getNext(needle);
        int j = 0;
        for (int i = 0; i < haystack.length(); i++)
        {
            while (j > 0 && haystack[i] != needle[j])
            {
                j = next[j - 1];
            }
            if (haystack[i] == needle[j])
            {
                j++;
                if (j == needle.length())
                    return i - j + 1;
            }
        }
        return -1;
    }
};
```

## 使用前缀数组减1

这样一来，比较的是j+1处的字符，而next[j]直接就是j+1之前（不包括j+1）处的最长公共前缀和后缀。

```cpp
class Solution {
public:
    void getNext(int* next, const string& s) {
        int j = -1;
        next[0] = j;
        for(int i = 1; i < s.size(); i++) { // 注意i从1开始
            while (j >= 0 && s[i] != s[j + 1]) { // 前后缀不相同了
                j = next[j]; // 向前回退
            }
            if (s[i] == s[j + 1]) { // 找到相同的前后缀
                j++;
            }
            next[i] = j; // 将j（前缀的长度）赋给next[i]
        }
    }
    int strStr(string haystack, string needle) {
        if (needle.size() == 0) {
            return 0;
        }
		vector<int> next(needle.size());
		getNext(&next[0], needle);
        int j = -1; // // 因为next数组里记录的起始位置为-1
        for (int i = 0; i < haystack.size(); i++) { // 注意i就从0开始
            while(j >= 0 && haystack[i] != needle[j + 1]) { // 不匹配
                j = next[j]; // j 寻找之前匹配的位置
            }
            if (haystack[i] == needle[j + 1]) { // 匹配，j和i同时向后移动
                j++; // i的增加在for循环里
            }
            if (j == (needle.size() - 1) ) { // 文本串s里出现了模式串t
                return (i - needle.size() + 1);
            }
        }
        return -1;
    }
};
```
