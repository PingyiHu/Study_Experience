# 原地哈希

# 做法

- 当不满足当前位置的条件，就不断把当前位置的信息送出去给别个
- 如果发现当前位置和别个位置的信息一样，就要停止送出去，结束循环

```python
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:

        for i in range(len(nums)):
            j = nums[i] - 1
            while 1 <= nums[i] <= len(nums) and nums[i] != i + 1 and nums[i] != nums[j]:
                j = nums[i] - 1
                nums[i], nums[j] = nums[j], nums[i]

        for i in range(len(nums)):
            if nums[i] != i + 1:
                return i + 1

                
        return len(nums) + 1

```
