# C++中队列的使用

Tags: 队列

在 C++ 中，队列（`queue`）是一个基于容器适配器（container adapter）的数据结构，遵循先进先出（FIFO, First-In-First-Out）的原则。队列提供了基本的队列操作，比如入队、出队、查看队首元素等。

C++ 标准库提供了 `std::queue` 容器适配器，默认使用 `std::deque`（双端队列）作为底层容器。你也可以选择 `std::list` 作为底层容器。队列的基本操作包括 `push`（入队）、`pop`（出队）、`front`（查看队首元素）、`back`（查看队尾元素）、`empty`（检查队列是否为空）和 `size`（获取队列大小）等。

### 基本用法

### 1. **头文件**

首先，需要包含头文件 `<queue>` 来使用队列：

```cpp
#include <queue>
```

### 2. **创建队列**

你可以创建一个空的队列，或者初始化一个包含元素的队列。

```cpp
#include <queue>
#include <iostream>

int main() {
    // 创建一个空的队列
    std::queue<int> q;

    // 入队操作
    q.push(10);
    q.push(20);
    q.push(30);

    // 查看队首元素
    std::cout << "Front element: " << q.front() << std::endl;  // 输出 10

    // 出队操作
    q.pop();
    std::cout << "Front element after pop: " << q.front() << std::endl;  // 输出 20

    // 查看队尾元素
    std::cout << "Back element: " << q.back() << std::endl;  // 输出 30

    // 检查队列是否为空
    std::cout << "Is queue empty? " << (q.empty() ? "Yes" : "No") << std::endl;  // 输出 No

    // 获取队列大小
    std::cout << "Queue size: " << q.size() << std::endl;  // 输出 2

    return 0;
}

```

### 主要操作

- **`push()`**：将元素添加到队尾（入队）。
- **`pop()`**：移除队首元素（出队），但不返回该元素。
- **`front()`**：返回队首元素，但不移除它。
- **`back()`**：返回队尾元素，但不移除它。
- **`empty()`**：检查队列是否为空。如果队列为空，返回 `true`，否则返回 `false`。
- **`size()`**：返回队列中元素的数量。

### 3. **示例代码说明**

```cpp
#include <queue>
#include <iostream>

int main() {
    // 创建一个空的队列
    std::queue<int> q;

    // 入队操作
    q.push(10);
    q.push(20);
    q.push(30);

    // 查看队首元素
    std::cout << "Front element: " << q.front() << std::endl;  // 输出 10

    // 出队操作
    q.pop();
    std::cout << "Front element after pop: " << q.front() << std::endl;  // 输出 20

    // 查看队尾元素
    std::cout << "Back element: " << q.back() << std::endl;  // 输出 30

    // 检查队列是否为空
    std::cout << "Is queue empty? " << (q.empty() ? "Yes" : "No") << std::endl;  // 输出 No

    // 获取队列大小
    std::cout << "Queue size: " << q.size() << std::endl;  // 输出 2

    return 0;
}

```

### 输出结果：

```
Front element: 10
Front element after pop: 20
Back element: 30
Is queue empty? No
Queue size: 2

```

### 4. **关于底层容器的选择**

- 默认情况下，`std::queue` 使用 `std::deque` 作为底层容器。但你也可以显式地指定使用 `std::list` 作为底层容器。
    
    ```cpp
    std::queue<int, std::list<int>> q;  // 使用 list 作为底层容器
    
    ```
    
    - `std::deque` 提供快速的插入和删除操作，适合队列操作。
    - `std::list` 提供了类似的功能，但它会消耗更多的内存，因为每个元素需要额外的指针来存储前后节点。

### 5. **总结**

- `std::queue` 是基于容器适配器的 FIFO（先进先出）数据结构，常用于模拟排队场景。
- 使用 `push()` 将元素添加到队列的尾部，使用 `pop()` 移除队首元素，使用 `front()` 和 `back()` 查看队首和队尾元素，使用 `empty()` 检查队列是否为空，使用 `size()` 获取队列中元素的数量。

这种结构非常适合处理任务队列、消息队列等情况，其中任务或数据按照顺序依次处理。
