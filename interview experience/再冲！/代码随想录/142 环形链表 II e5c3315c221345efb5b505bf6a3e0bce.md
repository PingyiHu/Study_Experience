# 142. 环形链表 II

Tags: 链表
URL: https://leetcode.cn/problems/linked-list-cycle-ii/description/

我的方法，空间复杂度与表长相关

```cpp
class Solution
{
public:
    ListNode *detectCycle(ListNode *head)
    {
        ListNode *cur = head;
        unordered_map<ListNode *, bool> address;
        while (cur && address.find(cur) == address.end())
        {
            address[cur] = true;
            cur = cur->next;
        }
        return cur;
    }
};
```
