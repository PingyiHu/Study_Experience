# 62. 不同路径

Tags: 动态规划
URL: https://leetcode.cn/problems/unique-paths/description/

# 我的方法

dp是到某个位置i，j的路径数量

dp[i][j] =  dp[i - 1][j] + dp[i][j - 1]

起点的那一行和那一列，都是只能单方向到达的，因此初始化为1。

```cpp
class Solution
{
public:
    int uniquePaths(int m, int n)
    {
        vector<vector<int>> dp(m, vector<int>(n, 0));
        for (int i = 0; i < m; i++)
            dp[i][0] = 1;
        for (int j = 0; j < n; j++)
            dp[0][j] = 1;

        for (int i = 1; i < m; i++)
            for (int j = 1; j < n; j++)
            {
                dp[i][j] =  dp[i - 1][j] + dp[i][j - 1];
            }
        return dp[m - 1][n - 1];
    }
};
```
