# 509. 斐波那契数

Tags: 动态规划
URL: https://leetcode.cn/problems/fibonacci-number/description/

# 我的方法

```cpp
class Solution {
public:
    int fib(int n) {
        vector<int> v(n + 1, 0);
        if (n > 0)
            v[1] = 1;
        for (int i = 2; i <= n; i++) {
            v[i] = v[i - 1] + v[i - 2];
        }
        return v[n];
    }
};
```

        vector<int> dp(N + 1);
        dp[0] = 0;
        dp[1] = 1;
        for (int i = 2; i <= N; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[N];
    }
};

# dp数组定义

动态规划里 **dp 数组的定义** 是整道题最关键的一步，甚至比转移方程还重要。

很多人做题时卡住，就是因为一开始 **状态定义不合理**，导致后面转移推不出来。

我帮你总结一个**通用的思考流程**，从题目到 dp 定义的 4 步法。

---

## 1. 明确问题类型（时空维度）

先看题目是处理什么类型的最优/计数/可行性问题：

- **线性结构**（数组、字符串） → 可能是一维或二维 dp
- **区间类**（区间合并、括号匹配、回文） → 多是二维 dp（`dp[i][j]` 表示区间 `[i,j]` 的结果）
- **背包类**（选取若干物品最优） → `dp[i][w]` 常见
- **树形/图** → 树形 dp（`dp[u][状态]`）
- **状态压缩** → 用二进制掩码 `dp[mask][...]`

---

## 2. 把题目答案拆成“子问题”

问自己一句话：**我要求的这个东西，能不能用更小规模的同类问题组合出来？**

例子 1：

- 题目：爬楼梯，一次 1 或 2 步，求走法数
- 子问题：走到第 `n` 层的方法数 = 走到 `n-1` + 走到 `n-2` 的方法数

例子 2：

- 题目：最长回文子串
- 子问题：`s[i..j]` 是否回文，可以由 `s[i+1..j-1]` 是否回文推导

---

## 3. 定义状态（dp 数组含义）

dp 数组**每个维度**都必须有明确含义：

- **下标表示的范围**：到第几个元素 / 从 i 到 j / 当前容量 / 当前状态
- **值的含义**：最优值？可行性（布尔值）？方案数（计数）？

**常见模式**：

1. `dp[i]` → 考虑前 i 个元素的答案（线性 dp）
2. `dp[i][j]` → 区间 `[i,j]` 的答案
3. `dp[i][w]` → 前 i 个物品，容量 w 的最优值（背包）
4. `dp[mask][u]` → 已访问的集合是 mask，当前在 u（状态压缩）

---

## 4. 选取维度 & 初始化依据

dp 维度要足够描述转移所需的信息，但不能过多导致不可算。

- **足够**：转移方程用到的全部信息都必须体现在状态里
- **不冗余**：不必存重复信息，否则会超时/超内存

---

### 示例 1：爬楼梯

题意：一次 1 或 2 步，n 阶

```cpp
// dp[i] 表示到达第 i 阶的方法数
dp[i] = dp[i-1] + dp[i-2]

```

**原因**：子问题只与楼梯编号有关，不需额外维度

---

### 示例 2：最长公共子序列 (LCS)

题意：两个字符串 a,b，求最长公共子序列长度

```cpp
// dp[i][j] 表示 a[0..i-1], b[0..j-1] 的 LCS 长度
if a[i-1] == b[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1
else:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])

```

**原因**：子问题依赖两个前缀位置，二维 dp 最简洁

---

### 示例 3：区间类（戳气球）

题意：戳区间 `[i,j]` 的气球最大得分

```cpp
// dp[i][j] 表示戳完区间 i..j 的最大得分
dp[i][j] = max(dp[i][k-1] + nums[i-1]*nums[k]*nums[j+1] + dp[k+1][j])

```

**原因**：转移依赖子区间拆分，所以需要 `[i,j]` 表示区间

---

## 快速判断 dp 定义是否合理的 3 问：

1. **状态能唯一确定子问题吗？**（不会丢信息）
2. **转移方程能只依赖更小的状态吗？**（符合无后效性）
3. **边界条件好写吗？**（初始化方便）
