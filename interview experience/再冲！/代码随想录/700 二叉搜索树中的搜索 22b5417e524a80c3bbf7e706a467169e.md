# 700. 二叉搜索树中的搜索

Tags: 二叉树
URL: https://leetcode.cn/problems/search-in-a-binary-search-tree/description/

# 我的方法

根据二叉搜索树的特征，左小于根小于右

```cpp
class Solution
{
public:
    TreeNode *searchBST(TreeNode *root, int val)
    {
        if (root == NULL)
            return NULL;
        if (root->val == val)
            return root;
        else if (root->val > val)
            return searchBST(root->left, val);
        else
            return searchBST(root->right, val);
    }
};
```
