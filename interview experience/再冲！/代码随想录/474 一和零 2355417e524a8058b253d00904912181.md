# 474. 一和零

Tags: 动态规划
URL: https://leetcode.cn/problems/ones-and-zeroes/description/

# 我的方法

dp数组的含义就是最大的0不超过m，1不超过n的子集。

dp是二维数组，第一维表示0的背包大小，第二维表示1的背包大小。

递推公式：dp[j][k] = max(dp[j][k], dp[j - nums[i][0]][k - nums[i][1]] + 1)

- 如果选择当前物品，那集合大小不变
- 如果不选择当前物品，那么腾出空间之后，再进行+1。

初始化，dp[0][0]是0，因为背包大小为0就是空集。

```cpp
class Solution {
public:
    int findMaxForm(vector<string>& strs, int m, int n) {
        vector<vector<int>> nums(strs.size(), vector<int>(2, 0));
        for (int i = 0; i < strs.size(); i++) {
            for (char c : strs[i]) {
                if (c == '0')
                    nums[i][0]++;
                else
                    nums[i][1]++;
            }
        }
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
        dp[0][0] = 0;
        for (int i = 0; i < nums.size(); i++) {
            for (int j = m; j >= nums[i][0]; j--)
                for (int k = n; k >= nums[i][1]; k--) {
                    dp[j][k] = max(dp[j][k], dp[j - nums[i][0]][k - nums[i][1]] + 1);
                }
        }
        return dp[m][n];
    }
};
```
