# 377. 组合总和 Ⅳ

# 随想录

在零钱兑换中说过了，此处是排列

```cpp
class Solution
{
public:
    int combinationSum4(vector<int> &nums, int target)
    {
        vector<uint64_t> dp(target + 1, 0);
        dp[0] = 1;
        for (int j = 0; j <= target; j++)
        { // 遍历背包容量
            for (int i = 0; i < nums.size(); i++)
            { // 遍历物品
                if (j - nums[i] >= 0)
                    dp[j] += dp[j - nums[i]];
            }
        }
        return dp[target];
    }
};
```
