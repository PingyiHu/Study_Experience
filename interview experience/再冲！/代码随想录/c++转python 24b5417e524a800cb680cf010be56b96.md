# c++转python

Tags: python基础

- 头文件/命名空间 → 模块/包：`#include <...>` → `import ...`；`std::` → 直接用或起别名 `import numpy as np`
- 基本容器
    - `vector<T>` → `list[T]`（可变、可混类型）；`array`→`list`/`array`/`numpy.ndarray`
    - `map<K,V>` → `dict[K,V]`，`unordered_map` 同样用 `dict`
    - `set`/`unordered_set` → `set`
- 遍历
    - `for (int i=0;i<n;i++)` → `for i in range(n):`
    - `for (auto &x : v)` → `for x in v:`
    - 带下标：`for i,x in enumerate(v):`
- 算法
    - `sort(v.begin(), v.end())` → `v.sort()`；返回新列表：`sorted(v, key=..., reverse=...)`
    - `lower_bound/upper_bound` → `bisect_left/right`（`bisect` 模块）
- 字符串
    - `std::string` → `str`；拼接 `+` 或 `''.join(list_of_str)`；格式化 `f"{x=}"`/`f"{x:.2f}"`
- I/O
    - `cin >>`/`cout <<` → `input()` / `print()`；多值：`a,b = map(int, input().split())`
- 引用/指针/拷贝
    - Python 变量都是“引用语义”；可变类型（list/dict/set）原地改会影响别处；用 `copy`/`deepcopy` 控制拷贝
- 常量/不可变
    - `const` 无直接等价；用约定（全大写）、`typing.Final` 或不可变类型（`tuple`, `frozenset`）
- 结构体/类
    - `struct`/POJO → `@dataclass`
    - 继承/虚函数 → 基类+覆盖；抽象接口用 `abc.ABC` + `@abstractmethod`
- 资源管理
    - RAII → `with` 上下文管理器（`with open(...) as f:`）
- 模板/泛型
    - 模板 → 动态类型；需要类型提示用 `typing.Generic[T]`
- 可变参数
    - `template<typename...>` → `args, **kwargs`
- 异常
    - `try { ... } catch (...)` → `try: ... except Exception as e: ...`
- 迭代器/生成器
    - `iterator` → `iter(obj)`；懒序列用 `yield` 生成器
- 并发
    - 线程/锁 → `threading`/`concurrent.futures`；多进程 → `multiprocessing`；异步 → `asyncio`
- 性能小贴士
    - 尽量用内置算法与向量化（`numpy`）、避免 Python 层循环；热点可用 `numba`/`cython`
