# 98. 验证二叉搜索树

Tags: 二叉树
URL: https://leetcode.cn/problems/validate-binary-search-tree/description/

# 我的方法

二叉搜索树的左子树的最大元素在最右下，右子树的最小元素在左下。

采用后序的方式，只有其所有的子树都是二叉搜索树，当前这个根节点代表的元素才能判断是否为二叉搜索树。

```cpp
class Solution {
public:
    int findLeftMax(TreeNode* root) {

        while (root->right) {
            root = root->right;
        }
        return root->val;
    }

    int findRightMin(TreeNode* root) {

        while (root->left) {
            root = root->left;
        }
        return root->val;
    }

    bool isValidBST(TreeNode* root) {
        bool left = false;
        bool right = false;
        if (root->left == NULL && root->right == NULL)
            return true;
        if (root->left) {
            int L_max = findLeftMax(root->left);
            if (L_max >= root->val)
                return false;
            left = isValidBST(root->left);
        } else
            left = true;

        if (root->right) {
            int R_min = findRightMin(root->right);
            if (R_min <= root->val)
                return false;
            right = isValidBST(root->right);
        } else
            right = true;

        return right && left;
    }
};
```

# 随想录

二叉搜索树的中序遍历是一个递增序列，只需要在中序遍历的过程中，判断是否严格递增即可。

```cpp
class Solution {
public:
    TreeNode* pre = NULL; // 用来记录前一个节点
    bool isValidBST(TreeNode* root) {
        if (root == NULL) return true;
        bool left = isValidBST(root->left);

        if (pre != NULL && pre->val >= root->val) return false;
        pre = root; // 记录前一个节点

        bool right = isValidBST(root->right);
        return left && right;
    }
};
```
