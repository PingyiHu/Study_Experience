# 343. 整数拆分

Tags: 动态规划
URL: https://leetcode.cn/problems/integer-break/description/

# 我的方法

n总可以拆分为2和3的组合

如果拆分的数字大于3，例如4或者5，他们本身并不大：

- 4可以拆为2+2，最大为4
- 5可以拆为2+3，此时其最大为6

因此记录2和3的个数即可：

- 如果当前组成该数字的2存在，就把2变3
- 如果2不存在了，就把一个3变成两个2

```cpp
class Solution
{
public:
    int integerBreak(int n)
    {
        if (n == 2)
            return 1;
        if (n == 3)
            return 2;
        vector<vector<int>> dp(n + 1, vector<int>(2, 0));
        // 0代表2的个数，1代表的是3的个数
        dp[4][0] = 2;

        for (int i = 5; i <= n; i++)
        {
            if (dp[i - 1][0] > 0)
            {
                dp[i][0] = dp[i - 1][0] - 1;
                dp[i][1] = dp[i - 1][1] + 1;
            }
            else
            {
                dp[i][0] = dp[i - 1][0] + 2;
                dp[i][1] = dp[i - 1][1] - 1;
            }
        }
        int result = pow(2, dp[n][0]) * pow(3, dp[n][1]);
        return result;
    }
};
```

# 随想录

dp[i]是当前整数拆分相乘的最大值。

dp[2]=1已知。

递推公式就是找到最大的 j * (j - i)或者是j * dp[(j - i)]

在遍历j的过程中实际上是把j也拆分了的，所以此处的j不需要拆分。

j≤i / 2的原因是要把数字切分为尽可能相似的块，这样值才会大（需要证明，可以当作结论）

```cpp
class Solution {
public:
    int integerBreak(int n) {
        vector<int> dp(n + 1);
        dp[2] = 1;
        for (int i = 3; i <= n ; i++) {
            for (int j = 1; j <= i / 2; j++) { //这个地方j <= n也是说得通的
                dp[i] = max(dp[i], max((i - j) * j, dp[i - j] * j));
            }
        }
        return dp[n];
    }
};
```
