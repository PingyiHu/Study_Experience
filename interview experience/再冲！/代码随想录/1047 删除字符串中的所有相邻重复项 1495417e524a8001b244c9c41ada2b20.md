# 1047. 删除字符串中的所有相邻重复项

Tags: 栈
URL: https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/description/

# 我的方法

用一个栈消除重复，再用一个栈进行输出。

```cpp
class Solution {
public:
    string removeDuplicates(string s) {
        stack<char> st;
        stack<char> output;
        for (int i = 0; i < s.size(); i++) {
            if (!st.empty() && st.top() == s[i])
                st.pop();
            else
                st.push(s[i]);
        }
        while (!st.empty()) {
            output.push(st.top());
            st.pop();
        }
        string ret = "";
        while (!output.empty()) {
            ret += output.top();
            output.pop();
        }
        return ret;
    }
};
```

# 随想录

```cpp
class Solution {
public:
    string removeDuplicates(string S) {
        stack<char> st;
        for (char s : S) {
            if (st.empty() || s != st.top()) {
                st.push(s);
            } else {
                st.pop(); // s 与 st.top()相等的情况
            }
        }
        string result = "";
        while (!st.empty()) { // 将栈中元素放到result字符串汇总
            result += st.top();
            st.pop();
        }
        reverse (result.begin(), result.end()); // 此时字符串需要反转一下
        return result;

    }
};
```
