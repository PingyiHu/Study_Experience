# 738. 单调递增的数字

Tags: 贪心
URL: https://leetcode.cn/problems/monotone-increasing-digits/description/

# 我的方法

把数字取出，逆序进行访问，找到最后第一个逆序的数字。

第一个逆序数字如果有连续的那么，得找最开始那个数字，从它开始。

逆序数字减一，左侧数字不变，右侧数字变成9（左侧是高位，右侧是低位）

```cpp
class Solution
{
public:
    int monotoneIncreasingDigits(int n)
    {
        vector<int> digits;
        int tmp = n;
        while (n != 0)
        {
            digits.push_back(n % 10);
            n /= 10;
        }
        int first = -1; // 找第一个逆序的数字的idx
        int pre = -1;
        for (int i = digits.size() - 1; i >= 1; i--)
        {
            if (first == -1)
            {
                if (digits[i] > digits[i - 1])
                {
                    if (pre >= 0 && digits[i] == digits[pre])
                        first = pre;
                    else
                        first = i;
                    break;
                }
                if (pre == -1 || i < digits.size() - 1 && digits[i] != digits[i + 1])
                {
                    pre = i;
                }
            }
        }
        if (first == -1)
            return tmp;
        else
        {
            int max = 0;
            for (int i = digits.size() - 1; i >= 0; i--)
            {
                if (i > first)
                    max = max * 10 + digits[i];
                else if (i == first)
                    max = max * 10 + digits[i] - 1;
                else
                    max = max * 10 + 9;
            }
            return max;
        }
    }
};
```

# 随想录方法

用to string得到一个高位在strNum[0]的数组

并且从后往前遍历。因为332，这样的情况，从前往后找到的flag是1，但是322这样的情况又不满足递增了，就变成329了；

从后往前就是322，找到的flag为0，这样就可以首位减1，首位之后的置为9。可以利用之前遍历的结果。

```cpp
class Solution {
public:
    int monotoneIncreasingDigits(int N) {
        string strNum = to_string(N);
        // flag用来标记赋值9从哪里开始
        // 设置为这个默认值，为了防止第二个for循环在flag没有被赋值的情况下执行
        int flag = strNum.size();
        for (int i = strNum.size() - 1; i > 0; i--) {
            if (strNum[i - 1] > strNum[i] ) {
                flag = i;
                strNum[i - 1]--;
            }
        }
        for (int i = flag; i < strNum.size(); i++) {
            strNum[i] = '9';
        }
        return stoi(strNum);
    }
};
```
