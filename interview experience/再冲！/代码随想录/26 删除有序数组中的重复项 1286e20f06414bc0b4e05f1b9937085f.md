# 26. 删除有序数组中的重复项

Tags: 双指针
URL: https://leetcode.cn/problems/remove-duplicates-from-sorted-array/submissions/525956656/

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int i = 0; // slow
        int j = 0; // fast
        int count = 1;
        for (; j < nums.size(); j++) {
            if (nums[j] != nums[i]) {
                nums[i + 1] = nums[j];
                i++;
                count++;
            }
        }
        return count;
    }
};
```
