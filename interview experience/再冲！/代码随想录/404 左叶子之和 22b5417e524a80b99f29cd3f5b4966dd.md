# 404. 左叶子之和

Tags: 二叉树
URL: https://leetcode.cn/problems/sum-of-left-leaves/description/

# 我的方法

传入是否为左子树的flag，然后前序遍历。

```cpp
class Solution
{
public:
    int get_left(TreeNode *root, bool is_left)
    {
        int sum = 0;
        if (root == NULL)
            return sum;
        
        if (is_left && root->left == NULL && root->right == NULL)
            return root->val;

        sum += get_left(root->left, true);
        sum += get_left(root->right, false);
        return sum;
    }

    int sumOfLeftLeaves(TreeNode *root)
    {
        return get_left(root, false);
    }
};
```

# 随想录

找到父节点之后，判断左节点是否为叶子节点。

```cpp
class Solution {
public:
    int sumOfLeftLeaves(TreeNode* root) {
        if (root == NULL) return 0;
        if (root->left == NULL && root->right== NULL) return 0;

        int leftValue = sumOfLeftLeaves(root->left);    // 左
        if (root->left && !root->left->left && !root->left->right) { // 左子树就是一个左叶子的情况
            leftValue = root->left->val;
        }
        int rightValue = sumOfLeftLeaves(root->right);  // 右

        int sum = leftValue + rightValue;               // 中
        return sum;
    }
};

```
