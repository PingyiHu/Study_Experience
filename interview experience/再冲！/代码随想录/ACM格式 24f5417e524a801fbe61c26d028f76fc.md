# ACM格式

Tags: python基础

## 1. 核心特点

1. **快速读取所有输入**（多组数据）
2. **一次性输出结果**
3. **不写多余提示**（不能 `print("请输入...")`）
4. **读到 EOF 结束** 或 **读到特定条件结束**
5. **数据格式灵活处理**（通常是标准输入 stdin）

---

## 2. 典型写法

### 2.1 固定数据组数

如果第一行给的是组数 `T`：

```python
T = int(input())
for _ in range(T):
    a, b = map(int, input().split())
    print(a + b)

```

输入：

```
3
1 2
3 4
5 6

```

输出：

```
3
7
11

```

---

### 2.2 读到 EOF（适合 ACM 多组未知数据）

```python
import sys

for line in sys.stdin:
    if line.strip() == "":
        continue
    a, b = map(int, line.split())
    print(a + b)

```

输入：

```
1 2
3 4
5 6

```

输出：

```
3
7
11

```

（EOF 表示输入结束，例如本地测试时 `Ctrl+D` / `Ctrl+Z`）

---

### 2.3 读到特定结束条件

```python
while True:
    a, b = map(int, input().split())
    if a == 0 and b == 0:
        break
    print(a + b)

```

输入：

```
1 2
3 4
0 0

```

输出：

```
3
7

```

## 3. Python ACM 模板

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    for a, b in zip(it, it):
        print(int(a) + int(b))

if __name__ == "__main__":
    main()

```

- **`sys.stdin.read()`** 一次性读完所有输入
- 适合数据量特别大、速度要求高的 ACM 题

---

## 4. 常见注意事项

- 不能有多余的输出提示（OJ 会判错）
- 注意换行、空格严格按照题目要求
- 对于大数据量，`input()` 可能超时，需用 `sys.stdin`
- 输出建议用 `\n` 拼接后一次性打印（减少 I/O 开销）
