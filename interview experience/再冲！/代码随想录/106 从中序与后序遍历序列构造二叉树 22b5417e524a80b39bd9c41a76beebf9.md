# 106. 从中序与后序遍历序列构造二叉树

Tags: 二叉树
URL: https://leetcode.cn/problems/construct-binary-tree-from-inorder-and-postorder-traversal/description/

# 我的方法

使用二叉树定义，将每一层的左右子树，再分为左子树的前序和后序。

```cpp
class Solution
{
public:
    TreeNode *buildTree(vector<int> &inorder, vector<int> &postorder)
    {
        if (inorder.empty())
            return NULL;
        int root_val = postorder[postorder.size() - 1];
        TreeNode *root = new TreeNode(root_val);
        auto root_it = find(inorder.begin(), inorder.end(), root_val);
        vector<int> left_inorder(inorder.begin(), root_it);
        vector<int> right_inorder(root_it + 1, inorder.end());
        int len_left = left_inorder.size();
        int len_right = right_inorder.size();
        vector<int> left_postorder(postorder.begin(), postorder.begin() + len_left);
        vector<int> right_postorder(postorder.begin() + len_left, postorder.begin() + len_left + len_right);
        root->left = buildTree(left_inorder, left_postorder);
        root->right = buildTree(right_inorder, right_postorder);
        return root;
    }
};
```
