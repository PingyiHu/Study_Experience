# 栈的使用

Tags: python基础

## 1. 用 `list` 实现栈

```python
stack = []

# 入栈
stack.append(1)
stack.append(2)
stack.append(3)

print(stack)  # [1, 2, 3]

# 出栈（LIFO - 后进先出）
top = stack.pop()
print(top)    # 3
print(stack)  # [1, 2]

```

- **`append()`**：把元素压入栈顶
- **`pop()`**：默认移除并返回栈顶元素（`pop(-1)`）

---

## 2. 用 `collections.deque` 实现栈（效率更好）

```python
from collections import deque

stack = deque()

stack.append('a')
stack.append('b')
stack.append('c')

print(stack)  # deque(['a', 'b', 'c'])

top = stack.pop()
print(top)    # c
print(stack)  # deque(['a', 'b'])

```

- `deque` 在栈顶操作是 **O(1)**，而 list 在末尾操作也通常是 O(1)，但在列表开头插入/删除会是 O(n)。

## 3. 栈的常用操作封装

```python
class Stack:
    def __init__(self):
        self.data = []

    def push(self, item):
        self.data.append(item)

    def pop(self):
        if not self.is_empty():
            return self.data.pop()
        return None

    def peek(self):
        if not self.is_empty():
            return self.data[-1]
        return None

    def is_empty(self):
        return len(self.data) == 0

    def size(self):
        return len(self.data)

# 示例
s = Stack()
s.push(10)
s.push(20)
print(s.peek())  # 20
print(s.pop())   # 20
print(s.size())  # 1

```
