# 968. 监控二叉树

Tags: 贪心
URL: https://leetcode.cn/problems/binary-tree-cameras/description/

# 随想录

设置3种状态： 0有覆盖，1有摄像头，2无覆盖

如果是子节点没有被覆盖，这个节点就需要摄像头。

如果当前这个节点的子节点都被覆盖了，这个节点就是没有被覆盖的

```cpp
class Solution {
public:
    int result = 0;
    int traverse(TreeNode* root) {
        if (root->left == NULL && root->right == NULL)
            return 2; // 0有覆盖，1有摄像头，2无覆盖
        int s_l = 0;
        int s_r = 0;
        if (root->left)
            s_l = traverse(root->left);
        if (root->right)
            s_r = traverse(root->right);
        if (s_l == 2 || s_r == 2) {
            result++;
            return 1;
        }
        if (s_l == 1 || s_r == 1)
            return 0;
        return 2;
    }
    int minCameraCover(TreeNode* root) {
        int state = traverse(root);
        if (state == 2)
            result += 1;
        return result;
    }
};
```
