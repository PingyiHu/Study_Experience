# 1049. 最后一块石头的重量 II

Tags: 动态规划
URL: https://leetcode.cn/problems/last-stone-weight-ii/description/

# 我的方法

这道题就是分割尽可能相等的两个集合，然后求两个集合的差值。

```cpp
class Solution {
public:
    int lastStoneWeightII(vector<int>& stones) {
        if (stones.size() < 2)
            return stones[0];
        sort(stones.begin(), stones.end());
        int sum = 0;
        for (int i = 0; i < stones.size(); i++) {
            sum += stones[i];
        }
        int half = sum / 2;

        vector<vector<int>> dp(stones.size(), vector<int>(half + 1, 0));
        for (int i = 0; i < stones.size(); i++)
            dp[i][0] = 0;
        for (int j = half; j >= stones[0]; j--)
            dp[0][j] = stones[0];

        for (int i = 1; i < stones.size(); i++) {
            for (int j = 1; j <= half; j++) {
                int a = dp[i - 1][j];
                int b = 0;
                if (j >= stones[i])
                    b = dp[i - 1][j - stones[i]] + stones[i];
                dp[i][j] = max(a, b);
            }
        }
        // 另一半的值由sum减去当前这半的值获得。
        return abs(sum - dp[stones.size() - 1][half] - dp[stones.size() - 1][half]);
    }
};
```
