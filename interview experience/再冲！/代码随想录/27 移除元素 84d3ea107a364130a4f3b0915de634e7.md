# 27. 移除元素

Tags: 双指针
URL: https://leetcode.cn/problems/remove-element/description/

我的解法

```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int i = 0;
        int j = nums.size() - 1;
        int count = 0;
        if (i == j && nums[i] == val)
            return 0;
        while (i < j) {
            while (i <= nums.size() - 1 && nums[i] != val)
                i++;
            while (j >= 0 && nums[j] == val) {
                count++;
                j--;
            }

            if (i < j) {
                int temp = nums[i];
                nums[i] = nums[j];
                nums[j] = temp;
            }
        }
        return nums.size() - count;
    }
};
```

快慢指针

快指针指向的是新数组中的那一些数值（找不等于删除元素的值） ，慢指针指向的是新数组的下标。

```cpp
// 时间复杂度：O(n)
// 空间复杂度：O(1)
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int slowIndex = 0;
        for (int fastIndex = 0; fastIndex < nums.size(); fastIndex++) {
            if (val != nums[fastIndex]) {
                nums[slowIndex++] = nums[fastIndex];
            }
        }
        return slowIndex;
    }
};
```
