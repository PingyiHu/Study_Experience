# 242. 有效的字母异位词

Tags: 哈希表
URL: https://leetcode.cn/problems/valid-anagram/description/

我的方法

umap为空则说明字符相同

```cpp
class Solution
{
public:
    bool isAnagram(string s, string t)
    {
        if (s.size() != t.size())
            return false;
        unordered_map<char, int> umap;
        for (int i = 0; i < s.size(); i++)
        {
            if (umap.find(s[i]) == umap.end())
                umap[s[i]] = 1;
            else
            {
                umap[s[i]]++;
                if (umap[s[i]] == 0)
                    auto n = umap.erase(s[i]);
            }

            if (umap.find(t[i]) == umap.end())
                umap[t[i]] = -1;
            else
            {
                umap[t[i]]--;
                if (umap[t[i]] == 0)
                    auto n = umap.erase(t[i]);
            }
        }
        if (umap.empty())
            return true;
        else
            return false;
    }
};
```

随想录

利用字符串全是小写的特性。

```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        int record[26] = {0};
        for (int i = 0; i < s.size(); i++) {
            // 并不需要记住字符a的ASCII，只要求出一个相对数值就可以了
            record[s[i] - 'a']++;
        }
        for (int i = 0; i < t.size(); i++) {
            record[t[i] - 'a']--;
        }
        for (int i = 0; i < 26; i++) {
            if (record[i] != 0) {
                // record数组如果有的元素不为零0，说明字符串s和t 一定是谁多了字符或者谁少了字符。
                return false;
            }
        }
        // record数组所有元素都为零0，说明字符串s和t是字母异位词
        return true;
    }
};
```
