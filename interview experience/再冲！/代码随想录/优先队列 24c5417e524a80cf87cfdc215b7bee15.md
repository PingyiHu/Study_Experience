# 优先队列

Tags: python基础

## 1. 优先队列的用途

- **总是快速获取最小（或最大）元素**
- 常用于：
    - Dijkstra 最短路径
    - Huffman 编码
    - 任务调度
    - Top-K 问题（取前 K 大/小元素）
    - 合并多个有序序列

---

## 2. 基本用法（`heapq` 模块）

### (1) 创建一个最小堆

```python
import heapq

data = [5, 1, 3, 7, 2]
heapq.heapify(data)  # 就地转换为最小堆
print(data)  # 内部是堆结构，不是排序
```

时间复杂度：`O(n)`

---

### (2) 插入元素（push）

```python
heapq.heappush(data, 0)
```

时间复杂度：`O(log n)`

---

### (3) 弹出最小值（pop）

```python
smallest = heapq.heappop(data)
```

时间复杂度：`O(log n)`

---

### (4) 同时 push 和 pop

```python
heapq.heappushpop(data, 4)  # 先 push 再 pop 最小值
```

---

### (5) 获取堆顶元素（不删除）

```python
min_val = data[0]
```

时间复杂度：`O(1)`

---

## 3. 最大堆实现

`heapq` 默认是最小堆，最大堆可以**取相反数**：

```python
max_heap = []
heapq.heappush(max_heap, -5)
heapq.heappush(max_heap, -1)
heapq.heappush(max_heap, -3)

largest = -heapq.heappop(max_heap)

```

---

## 4. 取前 K 小 / K 大元素

```python
nums = [5, 1, 3, 7, 2]
print(heapq.nsmallest(3, nums))  # [1, 2, 3]
print(heapq.nlargest(2, nums))   # [7, 5]

```

> 内部会用堆优化，复杂度比排序快。
> 

---

## 5. 合并多个有序序列

```python
a = [1, 4, 7]
b = [2, 5, 8]
c = [3, 6, 9]
for x in heapq.merge(a, b, c):
    print(x, end=' ')
# 输出：1 2 3 4 5 6 7 8 9

```

> 所有序列必须是有序的。
> 

---

## 6. 小结

- **模块**：`heapq`
- **核心方法**：
    - `heapify(list)` → 原地建堆
    - `heappush(heap, item)` → 入堆
    - `heappop(heap)` → 出堆（最小值）
    - `heappushpop(heap, item)` → 入堆再出堆
    - `heapreplace(heap, item)` → 出堆再入堆
    - `nsmallest(k, iterable)` / `nlargest(k, iterable)`
    - `merge(*iterables)` → 合并有序序列
- **性质**：
    - `heapq` 是最小堆，最大堆用负数技巧
    - 适合动态获取最小/最大值，效率高于每次全排序

# 注意

heapq.heappush可以使用元组进行输入：

- 必须保证元组的倒数第二维至少是可比的，下面的这个方式会报错，因为字典不可比
    
    ```python
    heapq.heappush(h, (1, {"id": 1}))
    heapq.heappush(h, (1, {"id": 2}))
    ```
    
- 如果不可比，需要加一个counter使其可比
    
    ```python
    import heapq, itertools
    
    h = []
    counter = itertools.count()
    heapq.heappush(h, (1, next(counter), {"id": 1}))
    heapq.heappush(h, (1, next(counter), {"id": 2}))
    print(heapq.heappop(h))
    # 输出 (1, 0, {'id': 1})
    ```
    
- 合并有序序列
    
    ```python
    import heapq
    
    def merge_k_sorted(arrs):
        h = []  # 最小堆，元素形如 (值, 序列编号 i, 该序列中的下标 j)
    
        # 1) 每个有序序列先放一个“头元素”进堆
        for i, arr in enumerate(arrs):
            if arr:  # 跳过空序列
                heapq.heappush(h, (arr[0], i, 0))
    
        out = []  # 合并后的结果
        # 2) 反复取出堆顶（全局最小值），然后把它所在序列的下一元素入堆
        while h:
            val, i, j = heapq.heappop(h)   # 取出当前所有头部里的最小值
            out.append(val)                # 放到结果中
            if j + 1 < len(arrs[i]):       # 该值来自第 i 个序列的 j 位置
                nxt = arrs[i][j + 1]       # 还有下一个元素
                heapq.heappush(h, (nxt, i, j + 1))
    
        return out
    
    ```
