# 我的方法

用一个bool数组去记录是否某个元素被访问过了，然后进一步递归。

不需要start index，因为不需要枝去重。

```python
def permute(nums):
    result = []
    path = []
    used = [False] * len(nums)

    def backtracking():
        if len(path) == len(nums):
            result.append(path.copy())
            return

        for i in range(len(nums)):
            if not used[i]:
                path.append(nums[i])
                used[i] = True
                backtracking()
                used[i] = False
                path.pop()

    backtracking()
    return result

```
