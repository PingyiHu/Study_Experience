# 300.最长递增子序列

Tags: 动态规划, 没做出来

# 随想录

dp[i]是考虑[0, i]的元素，**以nums[i]为结尾**的最长子序列（而不是考虑[0, i]所有元素的最长子序列长度，后者的这样的定义就不能像下面一样进行状态转移了，因为nums[i]不一定是考虑[0, i]的最大元素。）

状态转移的方式是dp[i]是j在[0,i-1]变化的过程中，满足nums[i]大于nums[j]的最长子序列加1

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        if (nums.size() <= 1) return nums.size();
        vector<int> dp(nums.size(), 1);
        int result = 0;
        for (int i = 1; i < nums.size(); i++) {
            for (int j = 0; j < i; j++) {
                if (nums[i] > nums[j]) dp[i] = max(dp[i], dp[j] + 1);
            }
            if (dp[i] > result) result = dp[i]; // 取长的子序列
        }
        return result;
    }
};
```
