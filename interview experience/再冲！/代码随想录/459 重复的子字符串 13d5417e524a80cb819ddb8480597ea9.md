# 459.重复的子字符串

Tags: KMP算法, 字符串
URL: https://leetcode.cn/problems/repeated-substring-pattern/

# 方法1：移动匹配

如果一个字符串S是由重复的子串构成，那么把这个字符串S重复2次，掐头去尾之后，一定可以重新拼凑出S。

```cpp
class Solution {
public:
    bool repeatedSubstringPattern(string s) {
        string t = s + s;
        t.erase(t.begin()); t.erase(t.end() - 1); // 掐头去尾
        if (t.find(s) != std::string::npos) return true; // r
        return false;
    }
};
```

# 方法2：KMP算法

最长前后缀不包含的子串，是最小不重复子串。

当最长前后缀不包含的子串的长度可以被整个字符串的长度整除时，说明字符串是由不包含子串构成的。

```cpp
class Solution {
public:
    void getNext (int* next, const string& s){
        next[0] = 0;
        int j = 0;
        for(int i = 1;i < s.size(); i++){
            while(j > 0 && s[i] != s[j]) {
                j = next[j - 1];
            }
            if(s[i] == s[j]) {
                j++;
            }
            next[i] = j;
        }
    }
    bool repeatedSubstringPattern (string s) {
        if (s.size() == 0) {
            return false;
        }
        int next[s.size()];
        getNext(next, s);
        int len = s.size();
        if (next[len - 1] != 0 && len % (len - (next[len - 1] )) == 0) {
            return true;
        }
        return false;
    }
};
```
