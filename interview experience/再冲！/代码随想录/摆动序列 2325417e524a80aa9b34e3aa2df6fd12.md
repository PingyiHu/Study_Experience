# 摆动序列

Tags: 贪心
URL: https://leetcode.cn/problems/wiggle-subsequence/

# 我的方法

双指针法，记录前一对数的差是否和当前这对数的差异号。

每次都是找局部的两个极值相减，比如考虑5和15，而不用考虑（1和15）或（15和8）

![image.png](%E6%91%86%E5%8A%A8%E5%BA%8F%E5%88%97/image.png)

```cpp
class Solution {
public:
    int wiggleMaxLength(vector<int>& nums) {
        if (nums.size() == 1)
            return 1;
        int i = 0;
        int k = 1;
        int result = 0;
        int pre = 0;
        while (k < nums.size()) {
            int temp = nums[k] - nums[i];
            if (temp == 0) {
                k++;
            } else {
                if (pre == 0 || (pre ^ temp) < 0) {
                    result += 1;
                    pre = temp;
                    i = k;
                    k++;
                } else {
                    i = k;
                    k++;
                }
            }
        }
        return result + 1;
    }
};
```

# 随想录方法

```cpp
class Solution {
public:
    int wiggleMaxLength(vector<int>& nums) {
        if (nums.size() <= 1) return nums.size();
        int curDiff = 0; // 当前一对差值
        int preDiff = 0; // 前一对差值
        int result = 1;  // 记录峰值个数，序列默认序列最右边有一个峰值
        for (int i = 0; i < nums.size() - 1; i++) {
            curDiff = nums[i + 1] - nums[i];
            // 出现峰值
            if ((preDiff <= 0 && curDiff > 0) || (preDiff >= 0 && curDiff < 0)) {
                result++;
                preDiff = curDiff; // 注意这里，只在摆动变化的时候更新prediff
            }
        }
        return result;
    }
};
```
