# 二叉树的dp原理

二叉树中存在直径和链路

- 直径：一个叶子节点连接到另一个叶子节点的路径，图中1到4的路径是一个直径
- 单侧链：
    - 在一个非叶子节点处其左节点或是右节点都可以有一条链，把他们和当前遍历的节点组合形成新的单侧链
    - 链的一端是叶子节点，另一端是非叶子节点（一个阶段也可以是一个链）

树状dp：

- 初始化一个全局需要比较的变量result
- 递归的过程中只向上**返回单侧的最大链（单侧链是一定经过当前根节点的）**
- 需要将当前递归到达节点处的**通过根节点的直径**和result值进行比较

```python
class Solution(object):

    def __init__(self):
        self.result = float("-inf")

    def postOrder(self, root):
        if root == None:
            return 0

        l = self.postOrder(root.left)
        r = self.postOrder(root.right)
        self.result = max(root.val + max(0,l) + max(0,r), self.result)

        return root.val + max(0, l, r)

    def maxPathSum(self, root):
        """
        :type root: Optional[TreeNode]
        :rtype: int
        """
        tmp = self.postOrder(root)
        return max(tmp, self.result)
```
