# 滑动窗口外循环是终止的位置

滑动窗口（Sliding Window）主要用于**处理连续区间、子数组、子串**类问题，尤其是需要在数据序列中不断移动一段区间来求解最优或统计信息时。

可以发现**滑动窗口的精妙之处在于：**

- 根据当前子序列和大小的情况，不断调节子序列的起始位置。从而将O(n^2)暴力解法降为O(n)。
- 指针i和j都不会走回头路。
- **当窗口内的内容满足要求时就开始动起始节点；当不满足要求的时候就动终止节点。**

在本题中实现滑动窗口，主要确定如下三点：

- 窗口内是什么？是满足题目效果的内容。
- 如何移动窗口的起始位置？(减少元素）
- 如何移动窗口的结束位置？（增加元素）

窗口的结束位置控制循环，窗口的起始位置不断减小，找符合要求的窗口。

我写的滑动窗口：

```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int left = 0;
        int right = 0;
        int sum = 0;
        int result = INT32_MAX;
        for (; right < nums.size(); right++) {
            sum += nums[right];
            while (sum >= target) {
                if (right - left + 1 < result)
                    result = right - left + 1;
                sum -= nums[left++];
            }
        }
        if (result == INT32_MAX)
            return 0;
        else
            return result;
    }
};
```

# 滑动窗口公式

正常情况for循环右节点一直往右，左节点在for循环内用while。

右节点满足条件的情况下扩展

不满足条件时左节点移动，直到满足要求

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        if not s:return 0
        left = 0
        lookup = set()
        n = len(s)
        max_len = 0
        cur_len = 0
        for i in range(n):
            cur_len += 1
            while s[i] in lookup:
                lookup.remove(s[left])
                left += 1
                cur_len -= 1
            if cur_len > max_len:max_len = cur_len
            lookup.add(s[i])
        return max_len

```
