# 135. 分发糖果

Tags: 贪心
URL: https://leetcode.cn/problems/candy/description/

# 我的方法

使用优先队列，记录rating和idx关系，每一次从队列中抽出最小的那个，然后比较，其和左右的rating，如果当前rating很大，那就取左右中较大的candy值+1作为当前节点的candy值。

```cpp
class Solution
{
public:
    struct cmp
    {
        bool operator()(const pair<int, int> &a, const pair<int, int> &b)
        {
            return a.first > b.first;
        }
    };

    int candy(vector<int> &ratings)
    {
        priority_queue<pair<int, int>, vector<pair<int, int>>, cmp> que; // rating, idx
        for (int i = 0; i < ratings.size(); i++)
        {
            que.push(make_pair(ratings[i], i));
        }
        vector<int> candy(ratings.size(), 0);
        int sum = 0;
        while (!que.empty())
        {
            auto p = que.top();
            int idx = p.second;
            int a = 1;
            int b = 1;
            if ((idx + 1 < ratings.size() && ratings[idx + 1] < ratings[idx]))
            {
                a = candy[idx + 1] + 1;
            }
            if (idx - 1 >= 0 && ratings[idx - 1] < ratings[idx])
            {
                b = candy[idx - 1] + 1;
            }
            candy[idx] = max(a, b);
            sum += candy[idx];
            que.pop();
        }
        return sum;
    }
};
```

# 随想录

从左往右遍历，如果当前节点比之前节点rating大，那就多1。

再由右往左遍历，如果当前节点比右侧节点rating大，那就在之前的candy数和右侧节点candy数+1中，选择较大的那一个。

```cpp
class Solution {
public:
    int candy(vector<int>& ratings) {
        vector<int> candyVec(ratings.size(), 1);
        // 从前向后
        for (int i = 1; i < ratings.size(); i++) {
            if (ratings[i] > ratings[i - 1]) candyVec[i] = candyVec[i - 1] + 1;
        }
        // 从后向前
        for (int i = ratings.size() - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1] ) {
                candyVec[i] = max(candyVec[i], candyVec[i + 1] + 1);
            }
        }
        // 统计结果
        int result = 0;
        for (int i = 0; i < candyVec.size(); i++) result += candyVec[i];
        return result;
    }
};
```
