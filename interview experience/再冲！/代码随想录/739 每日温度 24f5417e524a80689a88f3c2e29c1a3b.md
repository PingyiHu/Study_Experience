# 739. 每日温度

Tags: 单调栈

# 单调栈解决的问题

找到左侧或是右侧第一个比当前元素大的元素

要找右侧第一个比当前大的元素，就要保证：

- 栈内保存下标
- 保持栈内下标对应的元素是递减排列，当某一个元素入栈，需要把栈内小于它的数字全部出栈

```python
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& T) {
        stack<int> st; // 递增栈
        vector<int> result(T.size(), 0);
        for (int i = 0; i < T.size(); i++) {
            while (!st.empty() && T[i] > T[st.top()]) { // 注意栈不能为空
                result[st.top()] = i - st.top();
                st.pop();
            }
            st.push(i);

        }
        return result;
    }
};
```
