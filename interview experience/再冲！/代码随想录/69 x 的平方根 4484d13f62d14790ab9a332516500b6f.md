# 69. x 的平方根

Tags: 二分查找
URL: https://leetcode.cn/problems/sqrtx/description/

```cpp
class Solution {
public:
    int mySqrt(int x) {
        int left = 0;
        int right = 1.0 * x / 2 + 1;
        int rightBorder = 0;
        while (left <= right) {
            int mid = (left + right) / 2;
            long long temp = 1.0 * mid * mid;
            if (temp > x) {
                right = mid - 1;
            } else {
                left = mid + 1;
                rightBorder = left;
            }
        }
        return right;
    }
};
```

左闭右闭区间，找右边界就行，left总是指向目标后的一个，right指向目标或是目标左侧的一个。
