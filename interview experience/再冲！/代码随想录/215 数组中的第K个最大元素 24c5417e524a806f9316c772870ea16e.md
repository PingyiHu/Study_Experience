# 我的方法：堆排序

前K大用小顶堆

```python
class Solution(object):
    def findKthLargest(self, nums, k):
        """
        :type nums: List[int]
        :type k: int
        :rtype: int
        """
        hp = nums[:k]
        heapq.heapify(hp)
        for i in range(k, len(nums)):
            heapq.heappushpop(hp, nums[i])

        return hp[0]
```

# 随想录

使用快排为基准的选择方式

```python
class Solution(object):
    def findKthLargest(self, nums, k):
        """
        :type nums: List[int]
        :type k: int
        :rtype: int
        """
        return self.quicksort(nums, k)

    def quicksort(self, arr, k):
        pivot = arr[0]  # 选第一个元素为基准
        left = [x for x in arr[1:] if x <= pivot]
        right = [x for x in arr[1:] if x > pivot]
        len_left = len(left)
        len_right = len(right)
        if len_right == k - 1:
            return pivot
        elif len_right > k - 1:
            return self.quicksort(right, k)
        else:
		        # 如果是右边的个数小于k-1，那对于剩余的left就不是求前k大了，求的是前（k减去右侧的元素个数）
            return self.quicksort(left, k - len_right - 1)
```
