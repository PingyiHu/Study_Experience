# 121. 买卖股票的最佳时机

Tags: 动态规划
URL: https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/description/

# 随想录方法

dp需要有两个状态：

- 在第i天，仍持有股票，此时最多有多少钱。（可以是今天买的，也可以是之前就买了的）
    - 如果当天现买，会不会比之前买的要便宜。
- 在第i天，如果不持有股票，此时最多有多少钱。（可以一直不买，也可以买了又卖）
    - 如果当天卖掉，会不会比之前不持有股票要赚的多

只需要比较最后一天，持有和不持有的价钱即可，如果最后一天不持有，说明之前有某天卖出得到的利益更大。

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        vector<vector<int>> dp(prices.size(), vector<int>(2, 0));
        dp[0][0] = -prices[0];
        dp[0][1] = 0;
        for (int i = 1; i < prices.size(); i++) {
            dp[i][0] = max(-prices[i], dp[i - 1][0]);
            dp[i][1] = max(prices[i] + dp[i - 1][0], dp[i - 1][1]);
        }
        return max(dp[prices.size() - 1][1], dp[prices.size() - 1][0]);
    }
};
```
