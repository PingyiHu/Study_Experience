# python的循环遍历方式

Tags: python基础

我给你分成两部分讲：**Python 中的循环写法** 和 **跳过指定个数元素的方法**，并且帮你对照 C++ 的常见写法。

---

## 1. Python 循环常见写法（C++ 对照）

| C++ 写法 | Python 对应 | 说明 |
| --- | --- | --- |
| `for (int i=0; i<n; i++)` | `for i in range(n):` | 默认从 0 递增到 n-1 |
| `for (int i=a; i<b; i++)` | `for i in range(a, b):` | 递增步长默认 1 |
| `for (int i=a; i<b; i+=k)` | `for i in range(a, b, k):` | 步长可正可负 |
| `for (auto &x : vec)` | `for x in vec:` | 直接遍历元素 |
| 同时取下标与元素 | `for i, x in enumerate(vec):` | `i` 是下标，`x` 是值 |
| 反向循环 | `for i in reversed(range(n)):` | 或 `for x in reversed(vec):` |
| 双重循环 | `for i in range(n):\n    for j in range(m):` | 缩进区分嵌套 |

## 2. 跳过指定个数的元素

假设你有一个列表 `data`，要在循环中**跳过前 K 个元素**或**每次跳过若干元素**：

### **跳过前 K 个元素**

```python
data = [10, 20, 30, 40, 50]
K = 2

# 方法1：切片
for x in data[K:]:
    print(x)

# 方法2：range 控制下标
for i in range(K, len(data)):
    print(data[i])

```

C++ 对应：

```cpp
for (int i = K; i < data.size(); i++) {
    cout << data[i] << "\n";
}

```

---

### **循环中途跳过若干个元素**

比如当前下标是 i，要直接跳过后面的 `skip` 个：

```python
data = [10, 20, 30, 40, 50, 60]
skip = 2
i = 0
while i < len(data):
    print(data[i])
    i += skip + 1  # 当前元素+跳过的数量

```

C++ 对应：

```cpp
int i = 0;
while (i < data.size()) {
    cout << data[i] << "\n";
    i += skip + 1;
}

```

---

### **循环时选择性跳过（类似 continue）**

```python
data = [10, 20, 30, 40, 50]
for x in data:
    if x % 20 == 0:  # 满足条件就跳过
        continue
    print(x)

```

C++ 对应：

```cpp
for (auto x : data) {
    if (x % 20 == 0) continue;
    cout << x << "\n";
}
```

✅ **总结**

- **前 K 个不要** → 切片 `data[K:]` 或 `range(K, len(data))`。
- **每次跨 N 个** → 手动控制下标递增。
- **条件跳过** → `continue`。
