## 1. Python 中的“数组”类型选择

在 Python 里，C++ `int arr[]` 这种固定类型的数组并不常用，而是有三种常见选择：

| 需求 | Python 类型 | 特点 | C++ 对应 |
| --- | --- | --- | --- |
| 一般存储、长度可变 | `list` | 可以存不同类型元素（但通常存同类型） | `std::vector` |
| 数值计算高性能 | `numpy.ndarray` | 类似 C 数组，支持多维、批量运算 | `std::vector` / 原生数组 |
| 固定类型、节省内存 | `array.array` | 仅存单一数值类型 | C 风格数组 |

## 2. 一维数组

### 列表（最常用）

```python
arr = [1, 2, 3, 4]  # 定义
arr.append(5)       # 末尾添加
arr.pop()           # 删除末尾并返回
arr[1] = 10         # 修改元素
print(arr[0])       # 访问元素

```

C++ 对应：

```cpp
vector<int> arr = {1, 2, 3, 4};
arr.push_back(5);
arr.pop_back();
arr[1] = 10;
cout << arr[0];

```

## 3. 二维数组（列表套列表）

```python
# 定义 2x3 的二维数组
arr = [
    [1, 2, 3],
    [4, 5, 6]
]

print(arr[0][1])  # 访问第一行第二列 → 2
arr[1][2] = 9     # 修改第二行第三列

# 遍历
for row in arr:
    for val in row:
        print(val, end=" ")

```

C++ 对应：

```cpp
vector<vector<int>> arr = {
    {1, 2, 3},
    {4, 5, 6}
};
cout << arr[0][1];
arr[1][2] = 9;

```

## 4. 正确初始化二维数组（避免引用同一行）

只有对于不可变对象，可以使用 * ，否则如下初始化

```python
dp = [[{"r": 0, "c": 0} for _ in range(col)] for _ in range(row)]

```

**错误写法**（会导致所有行共享同一引用）：

```python
arr = [[0] * 3] * 2
arr[0][0] = 1
print(arr)  # [[1, 0, 0], [1, 0, 0]] ❌

```

**正确写法**：

```python
arr = [[0] * 3 for _ in range(2)]
arr[0][0] = 1
print(arr)  # [[1, 0, 0], [0, 0, 0]] ✅

```

## 5. 多维数组运算（用 NumPy）

当你需要像 C++ `int arr[100][100]` 那样高效处理数值时，用 **NumPy**：

```python
import numpy as np

arr = np.zeros((2, 3), dtype=int)  # 2x3 全 0
arr[0, 1] = 5
arr[1] = [7, 8, 9]
print(arr)

# 切片
print(arr[:, 1])  # 第二列

```

C++ 对应（二维 `int` 数组）：

```cpp
int arr[2][3] = {};
arr[0][1] = 5;

```

## 6. 高维数组

```python
import numpy as np
arr3d = np.zeros((2, 3, 4), dtype=int)  # 三维：2×3×4
arr3d[1, 2, 3] = 99
print(arr3d.shape)  # (2, 3, 4)

```

在 C++ 里类似：

```cpp
int arr[2][3][4] = {};
arr[1][2][3] = 99;

```

---

## 7. 小结

- **list** → 灵活、可变长，日常首选。
- **NumPy ndarray** → 高性能数值运算，多维支持好。
- 初始化二维数组要用 **列表推导**，防止引用同一行。
- Python 索引和切片比 C++ 更灵活（`arr[start:end:step]`）。
