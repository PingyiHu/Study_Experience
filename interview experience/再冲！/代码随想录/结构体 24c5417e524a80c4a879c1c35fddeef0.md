# 结构体

Tags: python基础

## 1. 用普通类（最灵活，接近 C++ struct）

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(3, 4)
print(p.x, p.y)

```

C++ 对应：

```cpp
struct Point {
    int x;
    int y;
};
Point p = {3, 4};

```

特点：

- 可以自由添加方法。
- 没有限制类型。
- 需要手写 `__init__` 构造方法。

---

## 2. 用 `collections.namedtuple`（轻量、不可变）

```python
from collections import namedtuple

Point = namedtuple('Point', ['x', 'y'])
p = Point(3, 4)
print(p.x, p.y)  # 3 4

```

C++ 对应：

```cpp
struct Point { int x; int y; };
const Point p = {3, 4};

```

特点：

- 属性可读不可写（不可变）。
- 内存占用小，适合存储大量简单数据。
- 不能轻易改值，需要新建实例。

---

## 3. 用 `dataclasses.dataclass`（推荐，最像 C++ struct）

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

p = Point(3, 4)
print(p.x, p.y)

```

C++ 对应：

```cpp
struct Point {
    int x;
    int y;
};
Point p = {3, 4};

```

特点：

- 自动生成 `__init__`、`__repr__`、`__eq__` 等方法。
- 语法简洁，支持类型注解。
- 默认可变，想要不可变加 `frozen=True`。
