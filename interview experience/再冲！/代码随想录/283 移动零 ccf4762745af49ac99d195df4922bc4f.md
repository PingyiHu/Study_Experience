# 283. 移动零

Tags: 双指针
URL: https://leetcode.cn/problems/move-zeroes/description/

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int i = 0; // slow
        int j = 0; // fast
        for (; j < nums.size(); j++) {
            if (nums[j] != 0) {
                int temp = nums[i];
                nums[i] = nums[j];
                nums[j] = temp;
                i++;
            }
        }
    }
};
```
