## **二、逐一说明与示例**

### 1. 定义字典

```python
d = {}  # 空字典
d = {'a': 1, 'b': 2}  # 字面量
d = dict(a=1, b=2)    # 用 dict 构造

```

C++ 对应：

```cpp
unordered_map<string, int> d;
```

---

### 2. 访问元素

```python
print(d['a'])  # 直接访问，键不存在会报 KeyError
```

C++ 对应：

```cpp
cout << d["a"];
```

---

### 3. 修改 / 添加键值对

```python
d['c'] = 3  # 添加新键
d['a'] = 10 # 修改已有键
```

C++ 对应：

```cpp
d["c"] = 3;
```

---

### 4. 删除键值对

```python
del d['a']      # 键不存在会报错
value = d.pop('b')  # 删除并返回值
d.clear()       # 清空字典
```

C++ 对应：

```cpp
d.erase("a");
d.clear();
```

---

### 5. 判断键是否存在

```python
if 'a' in d:
    print("存在")
```

C++ 对应：

```cpp
if (d.count("a")) { ... }
```

---

### 6. 获取键列表、值列表、键值对列表

```python
keys = list(d.keys())      # ['a', 'c']
values = list(d.values())  # [10, 3]
items = list(d.items())    # [('a', 10), ('c', 3)]
```

C++ 对应：

```cpp
for (auto& kv : d) { cout << kv.first << kv.second; }
```

---

### 7. 遍历字典

```python
# 遍历键
for k in d:
    print(k, d[k])

# 遍历键值对
for k, v in d.items():
    print(k, v)
```

C++ 对应：

```cpp
for (auto& [k,v] : d) { ... }
```

---

### 8. 默认值获取（`get()`）

```python
print(d.get('x', 0))  # 如果 'x' 不存在，返回 0
```

C++ 对应：

```cpp
auto it = d.find("x");
if (it != d.end()) return it->second; else return 0;

```

---

### 9. 批量更新（`update()`）

```python
d.update({'x': 100, 'y': 200})

```

C++ 对应：只能一个个赋值，没有一次性批量更新的标准方法。

---

### 10. 计数器用法（`collections.Counter`）

```python
from collections import Counter
cnt = Counter(['a', 'b', 'a'])
print(cnt)         # Counter({'a': 2, 'b': 1})
print(cnt['a'])    # 2

```

C++ 对应：

```cpp
unordered_map<char,int> cnt;
cnt['a']++;

```

---

### 11. 字典推导式

```python
squares = {x: x*x for x in range(5)}
```

C++ 对应：

```cpp
unordered_map<int,int> squares;
for (int x = 0; x < 5; x++) squares[x] = x*x;
```

---

### 12. 嵌套字典

```python
student = {
    'name': 'Tom',
    'scores': {'math': 90, 'english': 85}
}
```

访问：

```python
print(student['scores']['math'])
```

C++ 对应：

```cpp
unordered_map<string, unordered_map<string,int>> student;
student["scores"]["math"] = 90;
```

---

### 13. 字典的拷贝

```python
d_copy = d.copy()  # 浅拷贝
```

C++ 对应：

```cpp
auto d_copy = d;
```

---

### 14. 字典合并（Python 3.9+）

```python
d1 = {'a': 1}
d2 = {'b': 2}
merged = d1 | d2  # {'a': 1, 'b': 2}
```

C++ 对应：

```cpp
// 没有直接合并，需遍历插入
```
