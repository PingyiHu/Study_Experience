# 打家劫舍

Tags: 动态规划
URL: https://leetcode.cn/problems/house-robber/description/

# 我的方法

dp的意义是抢当前的这个屋子可以得到的最大收益。

dp[i]=max_num+nums[i]，其中max_num指的是除了dp[i-1]之外的之前的dp数组的最大值。

```cpp
class Solution
{
public:
    int rob(vector<int> &nums)
    {
        if (nums.size() == 2)
            return max(nums[0], nums[1]);
        else if (nums.size() == 1)
            return nums[0];
        vector<int> dp(nums.size(), 0);
        dp[0] = nums[0];
        dp[1] = nums[1];
        int pre = dp[1];
        int max_num = dp[0];
        for (int i = 2; i < nums.size(); i++)
        {
            dp[i] = max_num + nums[i];
            max_num = max(dp[i - 1], max_num);
        }
        return max(max_num, dp[nums.size() - 1]);
    }
};
```

# 随想录

dp是考虑0到当前这个房子可以得到的最大收益。

状态转移考虑当前这个房子偷还是不偷：

- 偷的话就考虑前2个房子的最大收益
- 不偷，就考虑前一个房子的最大收益

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        if (nums.size() == 0) return 0;
        if (nums.size() == 1) return nums[0];
        vector<int> dp(nums.size());
        dp[0] = nums[0];
        dp[1] = max(nums[0], nums[1]);
        for (int i = 2; i < nums.size(); i++) {
            dp[i] = max(dp[i - 2] + nums[i], dp[i - 1]);
        }
        return dp[nums.size() - 1];
    }
};
```
