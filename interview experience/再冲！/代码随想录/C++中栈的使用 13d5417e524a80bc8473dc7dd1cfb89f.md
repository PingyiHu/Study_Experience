# C++中栈的使用

Tags: 栈

在 C++ 中，`stack` 是一个基于容器适配器（container adaptor）提供的容器，它实现了后进先出（LIFO）的数据结构。`stack` 默认使用 `deque`（双端队列）作为底层容器，也可以使用 `vector` 或 `list`。你可以根据需求选择不同的底层容器类型。

### 1. **`stack` 的初始化**

你可以通过以下几种方式初始化一个 `stack`：

### 1.1 **使用默认构造函数**

默认构造函数会创建一个空的 `stack`，并且默认底层容器是 `deque`。

```cpp
#include <iostream>
#include <stack>

int main() {
    std::stack<int> s;  // 创建一个空的 stack，底层容器是 deque
    s.push(10);
    s.push(20);
    s.push(30);

    std::cout << "Top element: " << s.top() << std::endl;  // 输出 30
    return 0;
}

```

### 1.2 **使用指定的底层容器**

`stack` 允许指定底层容器（默认为 `deque`，也可以是 `vector` 或 `list`）。如果你想使用不同的容器，可以在创建时指定。例如：

```cpp
#include <iostream>
#include <stack>
#include <vector>

int main() {
    std::stack<int, std::vector<int>> s;  // 使用 vector 作为底层容器
    s.push(10);
    s.push(20);
    s.push(30);

    std::cout << "Top element: " << s.top() << std::endl;  // 输出 30
    return 0;
}

```

你可以看到，`stack` 通过模板参数指定了底层容器类型（此处是 `std::vector<int>`）。

### 1.3 **通过另一个 `stack` 初始化**

你还可以通过另一个已有的 `stack` 对象来初始化一个新的 `stack` 对象，类似于拷贝构造。

```cpp
#include <iostream>
#include <stack>

int main() {
    std::stack<int> s1;  // 创建一个空的 stack
    s1.push(10);
    s1.push(20);

    std::stack<int> s2(s1);  // 使用 s1 初始化 s2

    std::cout << "Top element of s2: " << s2.top() << std::endl;  // 输出 20
    return 0;
}

```

### 1.4 **通过容器初始化（直接初始化）**

`stack` 还允许通过已有的容器（如 `vector` 或 `deque`）来初始化。底层容器会从传入的容器中拷贝元素。

```cpp
#include <iostream>
#include <stack>
#include <deque>

int main() {
    std::deque<int> deque = {10, 20, 30};
    std::stack<int, std::deque<int>> s(deque);  // 使用 deque 初始化 stack

    std::cout << "Top element: " << s.top() << std::endl;  // 输出 30
    return 0;
}

```

### 2. **总结**

在 C++ 中初始化 `stack` 可以通过以下方式：

1. **默认构造函数**：`std::stack<int> s;`
2. **指定底层容器**：`std::stack<int, std::vector<int>> s;`
3. **通过已有 `stack` 对象拷贝初始化**：`std::stack<int> s2(s1);`
4. **通过已有容器初始化**：`std::stack<int, std::deque<int>> s(deque);`

在初始化时，通常选择底层容器 `deque`，因为它提供了良好的性能，特别是栈操作（如 `push` 和 `pop`）在两端都有高效的性能。如果你有特殊需求，可以根据场景选择其他容器，如 `vector` 或 `list`。
