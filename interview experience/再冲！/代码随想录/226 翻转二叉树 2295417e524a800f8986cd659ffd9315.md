# 226. 翻转二叉树

Tags: 二叉树
URL: https://leetcode.cn/problems/invert-binary-tree/description/

# 我的方法

层序遍历，节点左右颠倒

```cpp
class Solution
{
public:
    TreeNode *invertTree(TreeNode *root)
    {
        if (!root)
            return root;
        queue<TreeNode *> que;
        que.push(root);
        while (!que.empty())
        {
            int size = que.size();
            for (int i = 0; i < size; i++)
            {
                auto node = que.front();
                swap(node->left, node->right);
                que.pop();

                if (node->left)
                    que.push(node->left);
                if (node->right)
                    que.push(node->right);
            }
        }
        return root;
    }
};
```
