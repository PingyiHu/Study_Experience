# AMP混合精度训练

Owner: 吉祥 郑

# 为什么需要混合精度

享受fp16运算的快速和显存的低占用，同时避免溢出和误差：

- 只用FP32的话显存占用太高，运算的速度也较慢
- 使用FP16占用是下来了，速度也变快了，但是数字的表示范围也变小了：
    - 因为参数极其梯度值都比较小，使用FP16可能会出现下溢
    - 梯度会发生舍入

# 权重备份

- 把参数权重使用fp32备份
- 计算使用fp16
- 更新的时候把fp16的梯度加到fp32的权重上

# loss scaling

把loss放大，其实就是把梯度放大：

- 先放大loss，乘以系数α
- 在把fp16梯度加到fp32之前除以这个系数

loss scaling策略：

- 一开始的时候这个系数是比较大的
- 在训练的过程中检查是否存在上溢：
    - 如果溢出，把α减半
    - 如果梯度很小了，又可以把α变回来

# 精度累加

在乘法的时候，使用fp16，对fp16的数字进行加和汇总的时候，使用fp32保存结果：

- 比如softmax加和操作
- adam状态值的更新
