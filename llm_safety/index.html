    LLM 安全专题¶

    系统梳理 LLM 安全四大核心方向¶

    越狱攻击 · 后门攻击 · 提示注入 · Agent 安全

    四大安全方向¶

    • 越狱攻击与防御

      从竞争目标与泛化错配理论出发，覆盖 GCG、AutoDAN、PAIR、TAP 等经典攻击与前沿进展。

      关键词：竞争目标、泛化错配、对抗样本

      阅读章节

    • 后门攻击与防御

      梳理触发器植入、Sleeper Agents、BadChain 等训练时威胁与检测方法。

      关键词：触发器、植入攻击、供应链威胁

      阅读章节

    • :material-injection:{ .lg .middle } 提示注入攻击与防御

      从直接注入到间接注入，涵盖 Instruction Hierarchy、PALADIN 等防御框架。

      关键词：直接注入、间接注入、控制流劫持

      阅读章节

    • Agent 安全与防御

      工具调用安全、多 Agent 协作风险、MCP 协议安全等前沿议题。

      关键词：工具安全、权限控制、沙箱隔离

      阅读章节

    核心概念速查¶

    • 攻击目标

      • 让模型生成有害内容
      • 绕过安全对齐
      • 窃取敏感信息
      • 劫持控制流

    • 防御策略

      • 输入过滤和检测
      • 输出安全审核
      • 模型对齐训练
      • 沙箱隔离执行

    • 评估指标

      • 攻击成功率（ASR）
      • 防御成功率（DSR）
      • 响应质量
      • 计算开销
